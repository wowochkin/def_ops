# Выгрузка документов «Памяти народа»

Пакетная выгрузка документов частей, карт и ЖБД с pamyat-naroda.ru с раскладкой по папкам.
Запускается **на своём компьютере**: браузер открывается в видимом окне, проверку
безопасности проходит человек, скрипт ждёт и продолжает.

## Установка

```
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/playwright install chromium     # или --channel chrome, чтобы взять установленный Chrome
```

## Порядок работы

```
python pn_dump.py login                                   # пройти проверку, профиль сохранится
python pn_dump.py probe 123456789                         # один документ: проверить, что листы находятся
python pn_dump.py search --query "62 армия" --date-from 1942-09-01 --date-to 1943-02-28
python pn_dump.py search --index magazine --query "62 армия"   # журналы боевых действий
python pn_dump.py status
python pn_dump.py download                                # можно прерывать Ctrl+C и запускать снова
python pn_dump.py download --retry-errors
```

Общие ключи (ставятся перед командой): `--out` — папка выгрузки, `--delay` — пауза между
запросами (по умолчанию 2 с), `--channel chrome` — установленный браузер.

Если сайт снова показал проверку (или вернул 401/403, или HTML вместо данных), скрипт открывает
главную страницу в окне браузера и ждёт: пройдите проверку и нажмите Enter в терминале.

## Как скачиваются листы

Просмотрщик сайта подгружает листы по одному, поэтому `download` листает его сам, как человек:
открывает документ, нажимает «следующий лист» (или стрелку →), ждёт, пока браузер получит
следующее изображение, и сохраняет его прямо из этого ответа — повторно лист не запрашивается.
Документ считается законченным, когда счётчик «Лист N из M» дошёл до конца или два шага подряд
не принесли нового листа. Миниатюры отбрасываются.

Если счётчик показал больше листов, чем скачалось, документ получает статус `partial`
(видно в `status`), а `download --retry-errors` пройдёт его заново, не трогая уже сохранённые
листы. Проверка посреди документа — то же: пройдите её, документ начнётся сначала, готовые
листы пропускаются.

Перед массовой выгрузкой запустите `probe <id>` на документе в 5–10 листов. Он скачает листы
в `pn-out/_probe/<id>/листы/` и скажет, какую кнопку «дальше» нашёл и видит ли счётчик.
Если кнопка не та или счётчик не найден, задайте их явно (селекторы ищите в
`pn-out/_probe/<id>/controls.json`):

```
python pn_dump.py --next-selector ".viewer-next" --counter-selector ".viewer-counter" download
```

Другие ключи листания: `--step-timeout` — сколько ждать следующий лист (по умолчанию 10 с),
`--max-sheets` — предел листов на документ.

## Ограничения

- Поиск сайта (Elasticsearch) отдаёт не больше 10 000 записей на запрос. Если задан период
  (`--date-from` и `--date-to`), скрипт сам делит его пополам, пока каждая часть не уложится.
- Кнопка «дальше» и счётчик ищутся по типовым признакам: разметку просмотрщика я не видел,
  поэтому первый `probe` обязателен.
- Скрипт не обходит защиту сайта (без смены адресов, прокси и подмены браузера) и работает
  в один поток. Большие объёмы лучше согласовать с владельцем ресурса.
