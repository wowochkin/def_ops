# Запуск

Команды выполняются из корня репозитория.

## Настольное приложение

```bash
git pull origin main
npm install
npm run desktop:app
```

Открывается окно приложения. Вместе с ним поднимаются ядро, голос, советник, «Переигровка» и «Принять командование».
Голосовой сервис ставится сам, если его ещё нет.

Первый запуск займёт несколько минут, потому что пересобирается ядро на Rust. Следующие запуски быстрее.

## Только редактор в браузере

Сервисы запускаются во втором терминале.

```bash
npm run dev            # http://localhost:5173/
npm run dev:services   # советник, голос, модель
```

## Сборка установщика

```bash
npm run desktop:build
```
