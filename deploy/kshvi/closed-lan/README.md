# Закрытый контур КШВИ

Каталог содержит профиль локальной изоляции процесса для macOS Seatbelt. Он разрешает TCP только на `127.0.0.1` и `::1`; файлы и локальные процессы остаются доступны для тестового стенда.

Профиль не заменяет настройку физической LAN, межсетевого экрана и локального NTP. Перед приёмкой необходимо:

1. отключить маршруты внешней сети на стендовых узлах или запретить их на межсетевом экране;
2. развернуть PostgreSQL и сервисы КШВИ на узлах закрытой LAN;
3. включить локальный TLS по `deploy/kshvi/tls-proxy.conf`;
4. синхронизировать узлы с локальным NTP по `deploy/kshvi/ntp.conf`;
5. проверить SHA-256 всех ресурсов `packages/kshvi/assets/manifest.json`;
6. выполнить `node scripts/kshvi-offline-check.mjs --deny-external --output docs/release/kshvi/nonfunctional/offline.json`.

Результат `passed` возможен только при подтверждённой изоляции. `blocked` означает, что локальные ресурсы могут быть исправны, но физическое ограничение не доказано. Нельзя вручную превращать такой протокол в `passed`.
