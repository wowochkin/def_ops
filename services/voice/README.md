# Сервис голоса

Только работа со звуком для голосового управления настольным приложением: определение речи (VAD), конец
реплики (Smart Turn), распознавание (GigaAM) и синтез (Qwen3-TTS). Стек MLX — только Mac на Apple Silicon.

- `audio.py` — калибровка порогов, слушатель кадров микрофона (речь, перебивание, конец реплики), склейка реплик.
- `tts.py` — резка потока на фразы, группировка в куски синтеза, паузы между кусками, затухание конца.
- `tts_tail.py` — договаривание последнего слога (EOS на кадр позже).

Значения перенесены со стенда `scripts/voice-bench/talk_server.py` без изменений: они подобраны на слух.

```
./setup.sh          # окружение .venv
npm run test:voice  # тесты (без .venv — берётся $VOICE_PYTHON, иначе пропуск)
```

Чистая логика не импортирует MLX и torch на верхнем уровне и тестируется только с numpy.
