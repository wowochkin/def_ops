# Сервис голоса

Только работа со звуком для голосового управления настольным приложением: определение речи (VAD), конец
реплики (Smart Turn), распознавание (GigaAM) и синтез (Qwen3-TTS). Языковой модели здесь нет: разбор реплик и
реестр действий — в окне приложения (`apps/editor/src/voice`). Стек MLX — только Mac на Apple Silicon. Для
пользователя голос описан в `docs/system.md`, раздел 9.1.

- `audio.py` — калибровка порогов, слушатель кадров микрофона (речь, перебивание, конец реплики), склейка реплик.
- `tts.py` — резка потока на фразы, группировка в куски синтеза (живая фраза и заготовка), паузы между кусками, затухание конца.
- `tts_tail.py` — договаривание последнего слога (EOS на кадр позже).
- `models.py` — настоящие модели (Silero VAD, Smart Turn v3, GigaAM v3 e2e, модель озвучки — по умолчанию Qwen3-TTS 1.7B; смена на лету); MLX — в одной нити.
- `engines.py` — модели озвучки на выбор (параметры вызова — как в `scripts/voice-bench/engines.json`), выбор хранится в `<данные>/tts.json`; `--tts` подставляет свои веса.
- `fake.py` — поддельные модели для `--fake`: речь по громкости, реплики из `--fake-script`, синтез — тон.
- `voices.py` — образцы голоса и роли (`<данные>/voices/<id>/`, `roles.json`), проверка записи нового голоса.
- `server.py` — `/health` и WebSocket `/ws`: кадры микрофона → реплики, фразы `say` → звук, калибровка, голоса.

Значения перенесены со стенда `scripts/voice-bench/talk_server.py` без изменений: они подобраны на слух.

## Установка

```
brew install uv ffmpeg
services/voice/setup.sh      # окружение services/voice/.venv (Python 3.12), ~1–3 мин; то же — npm run voice:setup
```

`npm run desktop:app` делает это сам перед запуском (если окружения нет или оно неполное; отключить — `DEFOPS_NO_VOICE=1`).

Модели (Silero VAD, Smart Turn, GigaAM, Qwen3-TTS) скачиваются с Hugging Face при первом запуске сервиса, не при
установке: первый запуск — с интернетом и дольше обычного.

Встроенные образцы голоса — куски записей из `scripts/voice-bench/ref/` (в репозиторий не входят): Жуков —
`scripts/voice-bench/prepare_ref.sh <архивная запись.mp3>`, начальник штаба — `scripts/voice-bench/prepare_chief.sh
<запись голоса штаба.mp3>`; есть образец начальника штаба — он голос этой роли по умолчанию, посредник — Жуков. При первом запуске сервис копирует их в `<данные>/voices/`
(`--seed-refs` — другая папка стенда). Образцов нет — начальнику штаба нечем говорить: сначала запишите свой голос
в окне «Голоса» и назначьте его роли.

## Запуск

Обычно сервис запускает приложение (`apps/desktop/server/voice.mjs`): после остальных сервисов, если есть
`.venv/bin/python`, с данными в `<папка данных приложения>/voice`; упал — до трёх перезапусков подряд через 5 с;
состояние — `<данные>/voice/state.json`, шлюз отдаёт его как `GET /api/voice`. Порт уже отвечает — приложение
подключается к запущенному вручную сервису.

Вручную:

```
.venv/bin/python server.py --data ~/def-ops-data/voice            # порт 47645, настоящие модели
.venv/bin/python server.py --data /tmp/voice --fake \
    [--fake-script реплики.txt]                                   # поддельные модели, без MLX и torch
npm run test:voice  # тесты (без .venv — берётся $VOICE_PYTHON, иначе пропуск)
node scripts/voice-e2e.mjs [--no-stub] [--shots DIR] [--only panel,handsfree]   # сквозная проверка панели на --fake (--only — только эти части)
```

`--fake` нужен для тестов и сквозной проверки без Mac: речь определяется по громкости кадров, «распознанные»
реплики берутся по очереди из строк `--fake-script` (`{эхо}` в строке заменяется тем, что синтез говорил последним:
эхо штаба из динамиков; `{эхо} стоп` — эхо и «стоп» человека), синтез — тон. Пороги по умолчанию: `--vad 0.5
--barge-vad 0.8 --barge-ms 300 --end-ms 400 --barge-mode voice`.

Подавление эха (`aec.py`, WebRTC AEC3 из пакета `livekit`; проверка на синтетике — `tools/aec_probe.md`): `--aec on|off`,
по умолчанию включено, если пакет есть (`--aec on` без пакета — ошибка при запуске). Сервис говорит о нём в `ready`
(`aec: true`); тогда окно играет звук штаба в том же звуковом графе, что и микрофон, берёт микрофон без обработки
браузера (эхоподавление, шумоподавление и АРУ выключены) и шлёт кадры `[0x02][микрофон int16 × 512][опора int16 × 512]`:
опора — то, что в тот же миг ушло в динамики (ответы, пробы голоса, звук калибровки). Сервис вычитает эхо по опоре
до VAD, калибровки и распознавания. Кадр без заголовка (только микрофон) идёт как раньше.

Перебивание: `voice` — речь громче `barge_vad` дольше `barge_ms`; `word` — стоп-словом. В режиме `word`, пока штаб
говорит, кусок речи (от 0,5 с, затем каждые 0,25 с по мере роста, не дожидаясь конца реплики) распознаётся в нити
torch — его хвост не длиннее 1,75 с. Стоп-слово («стоп», «подождите», «подожди», «хватит», «отставить», «тихо») или
обращение «штаб…» в начале новой речи (до него — только эхо) — `barge`. Каждое стоп-слово судится само: эхо — только
в цепочке соседних слов текущей фразы штаба (уже отправленной в окно) в том же порядке (два слова в конце куска или
от трёх); одно «стоп» — всегда просьба человека. Громкость в этом режиме ничего не обрывает; реплика после «Стоп»
обрабатывается как обычно, а речь без стоп-слова, пока штаб говорит, — не реплика (её не отличить от эха): штаб её
не обрывает, окну она уходит отдельно (`over`) — окно принимает её, только если это короткий ответ на его вопрос
(«второй», «нет»), и тогда само останавливает штаб. Режим выбирает калибровка: эхо громче речи поверх штаба — `word`, иначе — `voice`.
Проба голоса не перебивается ни в каком режиме.

## Протокол

`GET /health` → `{"state": "loading"|"ready"|"error", "error"?}`. `WS /ws` на `127.0.0.1:47645`: двоичное — звук,
текст — JSON с полем `type`.

| Окно → сервис | |
|---|---|
| двоичные кадры | микрофон, int16, 16 кГц, по 512 отсчётов |
| `hello {settings}`, `settings {…}` | пороги: `vad`, `barge_vad`, `barge_ms`, `end_ms`; режим перебивания `barge_mode: voice\|word` |
| `say {id, role, text}` | сказать текст голосом роли (`chief` — начальник штаба, `umpire` — посредник) |
| `prepare {id, role, text}` | заготовить звук фразы заранее: синтез целиком сейчас, `say` того же текста тем же голосом играет его без синтеза |
| `stop {id?}`, `played {id}` | замолчать (всё или фразу); окно доиграло фразу |
| `calib {step: noise\|speech\|echo\|over\|finish\|cancel, sec}` | калибровка |
| `tts {op: list\|set, id?}` | модели озвучки: список / сменить (20–40 с загрузки; не загрузилась — остаётся прежняя) |
| `voice {op: list\|record-start\|record-stop\|discard\|preview\|save\|assign\|delete, …}` | голоса |

| Сервис → окно | |
|---|---|
| `ready {voices, roles, record_text, …}` | готовность |
| `level {p, busy}`, `speech {state: start\|end}` | уверенность речи; речь началась / кончилась |
| `utterance {id, text, audio_s, stt_ms, continues?}` | реплика; `continues` — склеена с прежней (пауза ≤ 2 с, ответ звучит < 1,5 с) |
| двоичные `[0x01][id u32][rate u32][pcm int16]` | звук фразы `say` |
| `prepared {id, audio_s?, error?}` | заготовка готова (длина звука, с) или не вышла — фраза тогда синтезируется как обычно |
| `say-done {id, stopped?}`, `barge {id}` | весь звук фразы отправлен / перебили; `stopped` — фразу остановили (окно `stop`, калибровка, запись голоса, отказ от записи — проба), её звук не доигрывается, `played` не шлётся |
| `echo {text}` | распознанное похоже на последнюю фразу штаба (пока он говорит или ≤ 1,5 с после) — эхо из динамиков, не реплика |
| `over {id, text, chief}` | перебивание «словом»: речь без стоп-слова, пока штаб говорит (он не оборван), и что он уже сказал; окно принимает её, только если это ответ на его вопрос (и тогда само останавливает штаб) |
| `calib_rec`, `calib_step`, `calib_result {cfg, stats, warn}`, `settings` | калибровка и выставленные пороги |
| `tts_list {engines, current, state: ready\|loading, error?}` (и в `ready.tts`) | модели озвучки и выбранная; `loading` — идёт смена |
| `voice_list`, `voice_recording`, `voice_check {ok, reasons, …}`, `voice_saved`, `voice_discarded` | голоса |
| `error {text}` | ошибка запроса или сбой (сессия продолжается); до `ready` — модели не загрузились |

Запись нового голоса не остаётся на диске, пока не сохранена: проверенная запись лежит во временном файле до
`save`; `discard`, новая запись или разрыв связи её стирают; `delete` стирает папку образца.

Чистая логика не импортирует MLX и torch на верхнем уровне и тестируется только с numpy.

## Проверка на Mac (ступень 1)

Всё — через динамики Mac, без наушников.

1. `services/voice/setup.sh` — завершается «готово»; есть `services/voice/.venv/bin/python`, в нём ставится
   `livekit` (подавление эха): `.venv/bin/python -c "import livekit.rtc"` без ошибки.
2. Встроенные образцы: есть `scripts/voice-bench/ref/*.wav` (иначе — `prepare_ref.sh` и `prepare_chief.sh` или пункт 11
   до калибровки); в окне «Голоса» у начальника штаба — «Начальник штаба, 10 с», у посредника — «Жуков, 10 с»;
   ответы штаба звучат голосом начальника штаба, не Жукова.
3. `npm run desktop:app` → значок микрофона внизу колонки разделов; панель: «Голос загружается» → (20–40 с, первый
   раз дольше — скачиваются модели) → запрос на микрофон → «Жду обращения». `curl -s localhost:8080/api/voice` —
   `"state":"ready"`.
4. Подавление эха включено: сервис сообщает его в `ready` —
   ```
   node -e 'const w = new WebSocket("ws://127.0.0.1:47645/ws"); w.onmessage = (e) => { const m = JSON.parse(e.data);
     if (m.type === "ready") { console.log("подавление эха:", m.aec); process.exit(0); } }'
   ```
   — `подавление эха: true`. В панели отдельной отметки нет; после калибровки (пункт 5) в «Замерах» «голос штаба
   в микрофоне» заметно ниже, чем «ваш голос». Для сравнения — ручной запуск с `--aec off` (приложение подключится
   к нему, раздел «Запуск»): там же — `false`, «голос штаба в микрофоне» выше; после смены режима — калибровка
   заново.
5. Калибровка, все четыре шага: на шаге «Голос штаба» звучит начальник штаба; в итоге — «Регуляторы выставлены»;
   советы понятны, совета про наушники нет. Тихие динамики — «перебить штаб можно, говоря дольше … мс»; громкие —
   «перебить штаб — словом» и «Динамики слышно громко — чтобы перебить штаб, скажите «Стоп».»
6. Стоп-слово (режим «словом» — выбран калибровкой или в «Тонкой настройке» → «Перебивать: словом»): пока штаб
   говорит, на панели «Перебить: скажите «Стоп»»; «Стоп» обрывает штаб за 0,6–0,9 с после начала слова; так же
   «Подождите», «Хватит», «Отставить», «Тихо», «Штаб, …»; ответ штаба из динамиков, где тоже звучит «штаб» (на «Штаб, что я
   могу сказать?»), сам его не обрывает; «Стоп, открой карты» — штаб замолкает, открываются «Карты».
7. Перебивание голосом (режим «голосом»): заговорить, пока говорит штаб, — он замолкает; его голос из динамиков
   сам его не обрывает.
8. «Штаб, открой переигровку» → открывается «Переигровка»; «Штаб, переигровка», «Штаб, карты» (без глагола) — тоже;
   «Штаб, что я могу?» (подсказка панели) и «Штаб, что я могу сказать?» → штаб перечисляет фразы;
   «Штаб, а можешь сделать ход?» → честный ответ. Распознавание ошиблось в слове («штап», «пере игровку»), но
   раздел открылся — в ленте «Услышано: «…» — понял: «…»».
9. Свободная фраза через модель (LM Studio запущена, модель загружена; в разделе «ИИ», карточка «Голос», — пусто
   или небольшая модель): «Штаб, давай-ка перейдём к картам» → «Думаю» → открываются «Карты», штаб говорит, что
   сделал; «Штаб, сыграй мне вальс» → «Этого система пока не предусматривает. Могу: …»; во время «Думаю» сказать
   «Штаб, открой знания» — открываются «Знания», старый ответ не звучит. LM Studio остановлена: бессмыслица после
   «Штаб» → один раз «Связь с моделью прервалась, повторяю запрос.», затем «Связи с моделью нет. Можно сказать,
   например: …»; «Штаб, открой переигровку» работает.
10. Управление и звук выключаются отдельно. «Выключить управление» (вопрос → «Выключить») → «Управление голосом
    выключено», индикатор микрофона в строке меню macOS гаснет, штаб на слова не отвечает; при этом посредник и экскурсии
    продолжают говорить (запустить «Штаб, расскажи о приложении» кнопкой или дождаться разбора хода); перезапуск —
    управление по-прежнему выключено, микрофон не спрашивается, свёрнутый значок перечёркнут с той же подписью;
    «Включить управление» — сразу «Жду обращения». «Выключить звук» (кнопка или «Штаб, выключи звук») → «Жду
    обращения · звук выключен»: микрофон открыт, команды исполняются, ответы — текстом в панели, речи нет; «Включить
    звук» / «Штаб, включи звук» — речь вернулась. «Штаб, отбой» — не выключение: «Дежурю. Скажите: «Штаб, на связь»»,
    микрофон открыт, исполняется только «Штаб, на связь».
11. Запись нового голоса: предупреждение и текст видны; запись тихо / с шумом / с ошибками в тексте — «Перечитайте
    текст» с причиной; хорошая — «Запись подходит», проба звучит новым голосом, «Сохранить» с именем; назначить
    «Начальник штаба» → ответы штаба этим голосом; «Не сохранять» — в `<данные>/voice` не остаётся `pending-*.wav`;
    «Удалить» — папка образца стёрта, роль вернулась к образцу по умолчанию. Проба голоса обрывается новой пробой,
    «Начать запись» и закрытием окна «Голоса»; речь в микрофон её не обрывает.
12. Разговор в комнате без обращения («передайте в штаб армии…», телевизор, второй человек) — в ленте серым
    «не мне», ничего не исполняется; голос штаба из динамиков не попадает в ленту как ваша реплика.
13. Пауза посреди фразы («Штаб, открой… [1 с] …переигровку») — в ленте одна реплика, а не две; штаб не отвечает
    на первую половину отдельно.
14. Закрыть приложение — процесс `server.py` не остаётся (`pgrep -f "server.py --port 47645"` пусто).

### Сценарий «без рук» (ступени 2–3, экскурсии)

Не касаясь мыши и клавиатуры, кроме запуска приложения и первого запроса macOS на микрофон. Проверять на Mac, через
динамики: распознавание, настоящий синтез, эхо и тексты экскурсий на настоящем голосе в сквозной проверке на
подставных моделях не проверяются.

15. Вступление. При запуске (если не выключено) — «О приложении · шаг 1 из 12», рамка на колонке разделов, штаб
    проговаривает шаги; «дальше», «назад», «повтори», «пауза», «продолжай», «хватит» работают словами; после
    вступления, если калибровки не было, штаб предлагает её — «да». «Штаб, не показывай вступление» — при
    следующем запуске вступления нет.
16. Туры разделов: «Штаб, тур по картам» (и по остальным разделам), «Штаб, покажи раздел» — текущий; при первом входе
    в раздел штаб предлагает показать. Где голосом можно не всё, тур говорит об этом честно.
17. Переигровка без рук: «Штаб, рассчитай берлинскую операцию» → «Штаб, принять командование» → окно зачитывается,
    «принимаю» → игра. «Доложи обстановку», «Дай три варианта» (штаб скажет, когда готовы), «выбираю второй»,
    «покажи Зелов», «оперативный уровень» (масштаб карты — 1:150 000; тактический — 1:50 000, стратегический — 1:300 000), «Штаб, подгони масштаб».
18. Необратимое только по «да»: «Штаб, проводи ход» → «Провожу ход: … Да?» (на панели крупно «Да» / «Нет»); «хорошо»,
    «ок», «давай» ход не подтверждают; молчание 15 с — «Отменяю — подтверждения не было».
19. После хода посредник: «Сведения о ходе готовятся, прошу подождать» → разбор на карте шагами (общее; до трёх
    боёв — карта переезжает к месту, метка и рамка; цели; тыл; противник — только то, что видит разведка). Уровень
    и масштаб карты меняются сами: бой и тыл — тактический (1:25 000 – 1:50 000), общее — оперативный или
    стратегический; после разбора уровень возвращается. Зоны влияния: своя — красноватая, противника — голубая;
    «покажи / скрой зоны влияния». «Повтори доклад» — коротко, «покажи ход» — разбор заново, «хватит» — остановить.
20. Подсветка исполненного голосом: «Штаб, оперативный уровень», «покажи Зелов» — на 2,5 с рамка у переключателя / метка
    на карте; мышью — без рамки.
21. Сохранение: «Штаб, сохрани запись игры» → файл в «Загрузках» (приложение, без окна выбора), штаб называет имя;
    имя занято — «имя (2).md». Разбор — «сохрани разбор».
22. Размер панели («Тонкая настройка» → «Размер панели»): обычный и крупный; модель озвучки (раздел «ИИ» →
    «Голос» → «Модель озвучки»): сменить на другую — 20–40 с загрузки, штаб молчит, затем говорит новой; не загрузилась —
    остаётся прежняя, причина под списком.
23. Устройства звука: подключить USB-микрофон или веб-камеру; «Тонкая настройка» → «Микрофон» — в списке появилось
    устройство; выбрать его — шкала «Слышу речь» реагирует на голос, штаб слышит; отключить — программа вернулась к
    системному микрофону и написала об этом; «Как в системе» + смена входа в Системных настройках → Звук — микрофон
    переоткрылся сам. «Вывод звука» виден, только если окно умеет его выбирать (иначе подсказка про Системные настройки).
24. Значок микрофона: свернуть панель в значок, перетащить мышью — остаётся на месте после перезапуска, за край окна не
    уходит; щелчок без сдвига разворачивает; «Штаб, верни значок на место» — вернулся сверху по центру.
