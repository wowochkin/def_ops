# Сервис голоса

Только работа со звуком для голосового управления настольным приложением: определение речи (VAD), конец
реплики (Smart Turn), распознавание (GigaAM) и синтез (Qwen3-TTS). Языковой модели здесь нет: разбор реплик и
реестр действий — в окне приложения (`apps/editor/src/voice`). Стек MLX — только Mac на Apple Silicon. Для
пользователя голос описан в `docs/system.md`, раздел 9.1.

- `audio.py` — калибровка порогов, слушатель кадров микрофона (речь, перебивание, конец реплики), склейка реплик.
- `tts.py` — резка потока на фразы, группировка в куски синтеза, паузы между кусками, затухание конца.
- `tts_tail.py` — договаривание последнего слога (EOS на кадр позже).
- `models.py` — настоящие модели (Silero VAD, Smart Turn v3, GigaAM v3 e2e, Qwen3-TTS 1.7B); MLX — в одной нити.
- `fake.py` — поддельные модели для `--fake`: речь по громкости, реплики из `--fake-script`, синтез — тон.
- `voices.py` — образцы голоса и роли (`<данные>/voices/<id>/`, `roles.json`), проверка записи нового голоса.
- `server.py` — `/health` и WebSocket `/ws`: кадры микрофона → реплики, фразы `say` → звук, калибровка, голоса.

Значения перенесены со стенда `scripts/voice-bench/talk_server.py` без изменений: они подобраны на слух.

## Установка

```
brew install uv ffmpeg
services/voice/setup.sh      # окружение services/voice/.venv (Python 3.12), ~1–3 мин
```

Модели (Silero VAD, Smart Turn, GigaAM, Qwen3-TTS) скачиваются с Hugging Face при первом запуске сервиса, не при
установке: первый запуск — с интернетом и дольше обычного.

Встроенные образцы голоса — куски архивной записи из `scripts/voice-bench/ref/` (в репозиторий не входят; готовит
`scripts/voice-bench/prepare_ref.sh <запись.mp3>`). При первом запуске сервис копирует их в `<данные>/voices/`
(`--seed-refs` — другая папка стенда). Образцов нет — начальнику штаба нечем говорить: сначала запишите свой голос
в окне «Голоса» и назначьте его роли.

## Запуск

Обычно сервис запускает приложение (`apps/desktop/server/voice.mjs`): после остальных сервисов, если есть
`.venv/bin/python`, с данными в `<папка данных приложения>/voice`; упал — до трёх перезапусков подряд через 5 с;
состояние — `<данные>/voice/state.json`, шлюз отдаёт его как `GET /api/voice`. Порт уже отвечает — приложение
подключается к запущенному вручную сервису.

Вручную:

```
.venv/bin/python server.py --data ~/def-ops-data/voice            # порт 47645, настоящие модели
.venv/bin/python server.py --data /tmp/voice --fake \
    [--fake-script реплики.txt]                                   # поддельные модели, без MLX и torch
npm run test:voice  # тесты (без .venv — берётся $VOICE_PYTHON, иначе пропуск)
node scripts/voice-e2e.mjs [--no-stub] [--shots DIR]   # сквозная проверка панели на --fake
```

`--fake` нужен для тестов и сквозной проверки без Mac: речь определяется по громкости кадров, «распознанные»
реплики берутся по очереди из строк `--fake-script`, синтез — тон. Пороги по умолчанию: `--vad 0.5 --barge-vad 0.8
--barge-ms 300 --end-ms 400`.

## Протокол

`GET /health` → `{"state": "loading"|"ready"|"error", "error"?}`. `WS /ws` на `127.0.0.1:47645`: двоичное — звук,
текст — JSON с полем `type`.

| Окно → сервис | |
|---|---|
| двоичные кадры | микрофон, int16, 16 кГц, по 512 отсчётов |
| `hello {settings}`, `settings {…}` | пороги: `vad`, `barge_vad`, `barge_ms`, `end_ms` |
| `say {id, role, text}` | сказать текст голосом роли (`chief` — начальник штаба, `umpire` — посредник) |
| `stop {id?}`, `played {id}` | замолчать (всё или фразу); окно доиграло фразу |
| `calib {step: noise\|speech\|echo\|over\|finish\|cancel, sec}` | калибровка |
| `voice {op: list\|record-start\|record-stop\|discard\|preview\|save\|assign\|delete, …}` | голоса |

| Сервис → окно | |
|---|---|
| `ready {voices, roles, record_text, …}` | готовность |
| `level {p, busy}`, `speech {state: start\|end}` | уверенность речи; речь началась / кончилась |
| `utterance {id, text, audio_s, stt_ms, continues?}` | реплика; `continues` — склеена с прежней (пауза ≤ 2 с, ответ звучит < 1,5 с) |
| двоичные `[0x01][id u32][rate u32][pcm int16]` | звук фразы `say` |
| `say-done {id}`, `barge {id}` | договорил / перебили |
| `calib_rec`, `calib_step`, `calib_result {cfg, stats, warn}`, `settings` | калибровка и выставленные пороги |
| `voice_list`, `voice_recording`, `voice_check {ok, reasons, …}`, `voice_saved`, `voice_discarded` | голоса |
| `error {text}` | ошибка запроса |

Запись нового голоса не остаётся на диске, пока не сохранена: проверенная запись лежит во временном файле до
`save`; `discard`, новая запись или разрыв связи её стирают; `delete` стирает папку образца.

Чистая логика не импортирует MLX и torch на верхнем уровне и тестируется только с numpy.

## Проверка на Mac (ступень 1)

1. `services/voice/setup.sh` — завершается «готово»; есть `services/voice/.venv/bin/python`.
2. Встроенные образцы: есть `scripts/voice-bench/ref/*.wav` (иначе — `prepare_ref.sh` или пункт 7 до калибровки).
3. `npm run desktop:app` → значок микрофона внизу колонки разделов; панель: «Голос загружается» → (20–40 с, первый
   раз дольше — скачиваются модели) → запрос на микрофон → «Жду обращения». `curl -s localhost:8080/api/voice` —
   `"state":"ready"`.
4. Калибровка, все четыре шага: на шаге «Голос штаба» звучит начальник штаба; в итоге — «Регуляторы выставлены»;
   советы (наушники и т. п.) понятны.
5. «Штаб, открой переигровку» → открывается «Переигровка»; «Штаб, что я могу?» (подсказка панели) и «Штаб, что я могу сказать?» → штаб
   перечисляет фразы;
   «Штаб, а можешь сделать ход?» → честный ответ; бессмыслица после «Штаб» → «Не понял вас. Можно сказать,
   например: …».
6. Разговор в комнате без обращения («передайте в штаб армии…», телевизор, второй человек) — в ленте серым
   «не мне», ничего не исполняется; голос штаба из динамиков не попадает в ленту как ваша реплика.
7. Пауза посреди фразы («Штаб, открой… [1 с] …переигровку») — в ленте одна реплика, а не две; штаб не отвечает
   на первую половину отдельно.
8. Перебивание: заговорить, пока говорит штаб, — он замолкает.
9. Запись нового голоса: предупреждение и текст видны; запись тихо / с шумом / с ошибками в тексте — «Перечитайте
   текст» с причиной; хорошая — «Запись подходит», проба звучит новым голосом, «Сохранить» с именем; назначить
   «Начальник штаба» → ответы штаба этим голосом; «Не сохранять» — в `<данные>/voice` не остаётся `pending-*.wav`;
   «Удалить» — папка образца стёрта, роль вернулась к образцу по умолчанию.
10. Закрыть приложение — процесс `server.py` не остаётся (`pgrep -f "server.py --port 47645"` пусто).
