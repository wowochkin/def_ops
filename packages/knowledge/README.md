# @def-ops/knowledge — база знаний

База по операциям 1945 года для двух задач: **обучение** (раздел «Знания» в редакторе — материалы, вопросы и
рассказы модели по ним) и **модель** (справка советнику в игре).

- `src/schema.ts` — каркас: 9 категорий (`CATEGORIES`) с подгруппами, ожидаемыми полями фактов и пометкой
  `gameSafe` (можно ли давать в игре вне вопросов истории); запись `Entry` — описание, факты `Fact` (значение,
  источник, достоверность A/B/C, цитата), связи `Relation`, статус (черновик / проверено / спорно).
- `src/search.ts` — поиск BM25 по русским основам слов (название и синонимы весят ×3), по записям и частям документов.
- `src/extract.ts` — документ → части (`chunkText`) → извлечение моделью по схеме `EXTRACT_SCHEMA` (каждый факт с
  дословной цитатой) → проверка цитат (`quoteFound`) → предложения `Proposal` (новая запись / дополнение) → `applyProposal`.
- `src/qa.ts` — материалы для ответа (`gather`), промпты вопроса и рассказа со ссылками `[n]` (`qaMessages`),
  справка для игры (`gameReference`: без вопросов истории — только доктрина и техника).
- `tools/build_seed.ts` (`npm run kb:seed`) — начальное наполнение `data/seed.json` из `docs/sources`, описания
  модели и `data/curated/*.json` (операции, сражения, местность, техника — пересказ фактов, не тексты книг).

Слой пользователя (свои правки, документы, предложения) хранится в редакторе в IndexedDB — `apps/editor/src/kb/`.
