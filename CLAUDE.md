# Правила работы в репозитории

## Описание системы — обновлять вместе с каждой доработкой

`docs/system.md` — единое описание системы (часть I — система, часть II — модель переигровки).
Любая доработка, которая меняет то, что умеет система, как она устроена, как считается модель
или как с ней работать, в том же коммите обновляет и описание:

1. **Текст.** Поправить или дописать нужные разделы `docs/system.md`: новое — в свой раздел,
   устаревшее — убрать, ссылки на разделы («раздел 19.3») проверить после перенумерации.
   Цифры результатов модели (часть II, раздел «Результаты») — только из свежего прогона
   (`npm run sim:demo`), не по памяти.
2. **Снимки экрана.** Изменился интерфейс — переснять затронутые снимки в `docs/img/`
   (Playwright, окно 1440×900, JPEG); новый экран — новый снимок с подписью курсивом под ним.
   Подпись описывает то, что на снимке действительно видно.
3. **PDF и Word.** `npm run docs:system` — собирает `docs/system.pdf` и `docs/system.docx`
   (нужны pandoc, python3 с python-docx — только для шаблона стилей, и браузер Playwright:
   `CHROMIUM_PATH=…`). Оба файла коммитятся вместе с `docs/system.md`. Стили Word —
   `docs/reference.docx` (пересобрать: `scripts/docx-reference.py`).
4. **В описании нет дат** (ни в шапке, ни «по состоянию на») и нет упоминаний ассистента
   и служебных названий веток.

Если доработка описания не касается (рефакторинг без изменения поведения, тесты), описание не трогается.

## Прочее

- Язык документации, интерфейса и сообщений коммитов — русский.
- Тексты книг в репозиторий не попадают — только извлечённые факты и короткие пересказы.
- Перед коммитом: `npm run typecheck` и `npm test`.
