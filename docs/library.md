# Библиотека условных знаков

Сгенерировано из `packages/core/src/library.ts` — не править вручную (`npm run docs:library`).

Всего элементов: **249**, категорий: **18**. Со ссылкой на первоисточник: **153**.

Первоисточники:

- **TM 30-430** — TM 30-430. Handbook on U.S.S.R. Military Forces. Chapter XII: Conventional Signs and Military Symbols. War Department, 1946 (таблицы знаков РККА 1942–1945)

Варианты оформления (система знаков одна, меняется только начертание; нормативное — только «Уставные знаки РККА», остальные воспроизводят манеру образцов карт):

- **Уставные знаки РККА** (норматив) — Начертание по таблице тактических условных знаков Красной Армии 1942–1945 (TM 30-430, гл. XII). Единственный вариант, основанный на нормативе: штабы — флажками по ступеням, танки — ромбами, свои — красным, противник — синим.
- **Историческая карта** (по образцу) — Манера военно-исторических карт и схем по двум образцам — карте Берлинской операции из атласа и схеме штурма Рейхстага: объёмные стрелки ударов, линии фронта и положение частей по датам, овалы объединений. Не норматив.
- **Инфографика** (по образцу) — Манера современной схемы-инфографики по образцу «Разгром берлинской группировки»: крупные плоские стрелки, полоса наступающих, укрепления с зубцами. Не норматив.

Пометка **⚠ сверить** — начертание не подтверждено перечисленными источниками (знаки исторических карт, флот, партизаны, разграничительные линии армий и фронтов); его нужно сверить с таблицей, принятой для проекта.
