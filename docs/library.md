# Библиотека условных знаков

Сгенерировано из `packages/core/src/library.ts` — не править вручную (`npm run docs:library`).

Всего элементов: **167**, категорий: **17**. Цвета по уставу: свои — красным, противник — синим, сооружения, заграждения и топография — чёрным.

Стили оформления:

- **Уставной** — Знаки рабочей (штабной) карты по системе советских тактических условных обозначений: свои — красным, противник — синим, сооружения — чёрным.
- **Атлас** — Оформление карт исторических атласов: стрелки-клинья с градиентом, многоцветные линии фронта по датам, овалы объединений.
- **Инфографика** — Современная схема-инфографика: крупные плоские стрелки, полоса наступающих, укрепления с зубцами.
- **Тактическая схема** — Крупномасштабная схема боя: позиции полков по датам, объёмные стрелки атак, оборона противника в городе.

Пометка **⚠ сверить** — у знака в разные годы были варианты начертания; его нужно сверить с таблицей условных знаков, принятой для проекта (например, «Тактические условные знаки», 1942, или послевоенные «Условные обозначения, применяемые в боевых документах»).
