# Библиотека условных знаков

Сгенерировано из `packages/core/src/library.ts` — не править вручную (`npm run docs:library`).

Всего элементов: **314**, категорий: **18**. Со ссылкой на первоисточник: **237**.

Первоисточники:

- **TM 30-430** — TM 30-430. Handbook on U.S.S.R. Military Forces. Chapter XII: Conventional Signs and Military Symbols. War Department, 1946 (таблицы знаков РККА 1942–1945)
- **ОУО** — Основные условные обозначения, применяемые в боевых документах (учебная таблица тактических знаков СА)
- **Веремеев** — Веремеев А. Условные обозначения, применяемые в боевых документах Советской Армии (по: Помбрик И.Ю., Шевченко Н.А. Рабочая карта командира. М.: Воениздат, 1967; Боевой устав Сухопутных войск, ч. 3, 1983)

Стили оформления:

- **РККА 1942–45** — Тактические знаки Красной Армии военного времени (TM 30-430, гл. XII): свои — красным, противник — синим; штабы — флажками по ступеням, танки — ромбами, ДОТ и ДЗОТ — квадратами со стрелкой.
- **СА 1967–83** — Знаки Советской Армии («Рабочая карта командира» 1967, БУСВ 1983, «Основные условные обозначения»): мотострелковые, танковые, ВДВ — красным; артиллерия, инженерные, химические войска и связь — чёрным; противник — синим; маршруты — коричневым; надписи — наклонным чертёжным шрифтом.
- **Атлас** — Оформление карт исторических атласов: стрелки-клинья с градиентом, многоцветные линии фронта по датам, овалы объединений.
- **Инфографика** — Современная схема-инфографика: крупные плоские стрелки, полоса наступающих, укрепления с зубцами.
- **Тактическая схема** — Крупномасштабная схема боя: позиции полков по датам, объёмные стрелки атак, оборона противника в городе.

Пометка **⚠ сверить** — начертание не подтверждено перечисленными источниками (знаки исторических карт, флот, партизаны, разграничительные линии армий и фронтов); его нужно сверить с таблицей, принятой для проекта.
