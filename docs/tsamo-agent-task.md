# Задание: подготовка данных из ЦАМО для модели переигровки

Задание для агента с браузером на компьютере пользователя: портал «Память народа» открывается
только в браузере, капчу проходит пользователь. Скилл — `/pamyat-naroda`.

## Зачем

Модель переигровки сверяется с историей по суточным положениям армий и датам событий. Первая
выборка из журналов боевых действий 12 армий (`docs/sources/vistula-oder-1945-tsamo.json`) уже
дала больше, чем любая подгонка правил:

- нашла армии, которые в сценарии неделями стояли в резерве или ждали приказа, хотя по журналу
  уже шли маршем;
- показала, что прежние «положения армий» — это неточные главные силы, а не передовые отряды;
- дала опору для выделения корпусов и передовых отрядов.

Что ещё нужно (по убыванию пользы):

1. **Положения армий, которых в выборке ещё нет.** На юге модель опережает историю на 3–6 суток
   (Краков, Катовице, Ченстохов, Оппельн), а 4-я танковая армия не выходит к Одеру у Штейнау.
2. **Когда и какие задачи армии получали.** Боевые распоряжения и приказы фронтов армиям и армий
   корпусам: сроки приказов в сценарии — главный источник ошибок.
3. **Немецкие войска по разведке.** Немецкие дивизии на Висле заданы шаблонами штатов. Из-за этого
   оборона в модели плотнее, чем в источниках, и полосы прорываются медленнее истории.
4. **Горючее танковых армий.** Сейчас расход в модели — допущение. Опора есть одна запись: 2 гв.
   ТА осталась без горючего 30.01.
5. **Берлинская операция по тем же армиям.** Тогда обе операции будут сравниваться на однотипных
   данных.
6. **Познань.** Нужно знать, когда замкнулось кольцо, кто его замкнул и какой был гарнизон.

## Общие правила

- **Источник — только документ.** Каждая запись — из конкретного документа ЦАМО: фонд, опись,
  дело, лист, ссылка на карточку `https://pamyat-naroda.ru/documents/view/?id=…`. Книги и
  справочники сюда не вносить.
- **Тексты документов не переписывать.** В поле `place` (или `text`) — короткий пересказ своими
  словами или выписка рубежа, не длиннее 300 знаков. Цитата (`quote`) — не длиннее 25 слов, только
  если без неё теряется смысл (например, «с утра 20.01 марш…»).
- **Скачивание.** Сканы скачивать только после согласия пользователя: перечислить документ, шифр и
  число листов. Сохранять в `tsamo-scans/<армия>/`, имена — `<армия>_<тип>_<фонд>-<опись>-<дело>_л<лист>.jpg`.
  В репозиторий сканы не попадают.
- **Неторопливо.** Один запрос за раз. Капчу проходит пользователь, агент её не обходит.
- **Координаты.** WGS84, `lat`/`lon` с 2–4 знаками. `approxKm` — радиус неопределённости: пункт
  найден точно — 2–3; рубеж из нескольких пунктов — половина его длины; район — его радиус. Если
  пункт не найден, координаты `null`, а в `note` — как он написан в документе. Немецкие названия
  давать вместе с польскими (Бромберг = Bydgoszcz, Шнайдемюль = Piła).
- **Время.** Дата — `YYYY-MM-DD`. Время — как в документе (`"19.00"`, `"к исходу дня"`, `"утро"`).
  Если документ изложен по периодам, а не по суткам, так и написать в `note`: «дата условная,
  период 20–22.01».
- **Чего нет, тоже записывать.** В `manifest.json` отмечать, какие документы просмотрены и какие дни
  в них не покрыты. Пустой результат — тоже результат.

## Где искать

Поиск — раздел «Документы» на портале (`https://pamyat-naroda.ru/documents/`), форма поиска по
названию части, автору, датам, виду документа и шифру. Через браузер на открытой странице можно
выполнять тот же запрос, что делает сайт: POST на
`https://cdn.pamyat-naroda.ru/ind/pamyat/document,map/_search` (документы и карты) и
`…/pamyat/magazine/_search` (журналы боевых действий), тело — запрос Elasticsearch,
`Content-Type: text/plain`. Пример:

```json
{"size": 50, "from": 0,
 "query": {"bool": {
   "must": [{"query_string": {"query": "4 танковой армии", "default_field": "document_name", "default_operator": "and"}}],
   "filter": {"bool": {"must": [{"range": {"document_date_b": {"gte": "1945-01-10", "lte": "1945-02-05"}}}]}}
 }}}
```

Полезные поля: `fond`, `opis`, `delo`, `list`, `document_name`, `document_date_b`, `document_date_f`,
`authors`, `document_type`, `image_path`, `geo_names`, `operation_name`, для ЖБД — `date_from` и
`date_to`. Поиск по `operation_name` («Висло-Одерская», «Берлинская») иногда находит то, что не
находится по названию части. Адреса проверить на живом сайте (скилл советует посмотреть сетевые
запросы при первом поиске). Если сайт отвечает иначе — работать через форму.

### Какие документы что содержат

| Вид документа на портале | Что из него брать |
|---|---|
| Журнал боевых действий армии, корпуса | положения главных сил, передовых отрядов, КП по дням; характер действий; иногда — получение задач |
| Оперативные сводки штаба (утренние и вечерние) | рубежи всех армий фронта на одно время; удобно для сверки |
| Боевые распоряжения, боевые приказы, директивы фронта | когда и какую задачу получила армия (корпус), куда наступать, к какому сроку |
| Боевые донесения армии фронту | положение на время донесения, состояние частей, горючее и боеприпасы |
| Разведывательные сводки и донесения (разведотдел штаба фронта, армии) | немецкие дивизии перед фронтом: нумерация, численность, положение, резервы |
| Схемы группировки противника, отчётные карты, карты обстановки (раздел «Карты») | положения своих и немецких войск на дату; рубежи, КП |
| Отчёты о проведённой операции (штабы фронтов и армий, обычно февраль–март 1945) | сводные таблицы: темпы по дням, силы сторон, потери, расход горючего и боеприпасов |
| Отчёты и донесения тыла (о наличии и подаче горючего, боеприпасов) | заправки и боекомплекты по дням, когда кончилось горючее |

Немецкие документы: в ЦАМО есть фонд трофейных германских документов (ф. 500), часть которого
оцифрована и выложена проектом «Германские документы в российских архивах» —
<https://germandocsinrussia.org>. Нужно проверить, есть ли там документы группы армий «А»
(Heeresgruppe A), 4-й танковой армии, 9-й и 17-й армий за январь 1945 года: оперативные карты
(Lagekarten), сводки численности (Stärkemeldungen), журналы боевых действий (KTB). Это необязательная
часть: делать после пунктов 1–4 и только если материалы находятся.

## Порядок работы

Каждый шаг — отдельный файл результата (структура — ниже). После каждого шага — короткая сводка
пользователю.

**Шаг 1. Положения армий Висло-Одерской, которых нет в первой выборке**, 12.01–03.02.1945,
журналы боевых действий. Порядок:

1. 4-я танковая армия — особенно 14–24.01: выход к Одеру у Штейнау 22.01, горючее.
2. 59-я и 60-я армии — юг: Краков, Катовице.
3. 3-я гвардейская танковая армия — Ченстохов, Оппельн, поворот на Силезию.
4. 5-я гвардейская армия.
5. 1-я гвардейская танковая армия, 47-я армия, 61-я армия.
6. При возможности — корпуса: 7-й гв. кк, 1-й гв. кк, 9-й и 11-й танковые, 4-й гв. и 31-й
   танковые.

По уже собранным армиям — дни, которых нет в первой выборке. Для 3 УА особенно 18–24.01:
когда именно начался марш.

**Шаг 2. Сроки и содержание задач**, 12.01–03.02.1945: боевые распоряжения и приказы штабов 1 БФ
(ф. 233) и 1 УФ (ф. 236) армиям; распоряжения армий корпусам. Важнее всего:
- 4 ТА 14–17.01 — когда получила задачу идти от Кельце на северо-запад;
- 3 гв. ТА 18–24.01 — поворот на Силезию;
- 59 и 60 А — Краков;
- выделение корпусов к Познани (8 гв. А, 69 А, 1 гв. ТА) 23–26.01;
- армейский подвижной отряд 5 УА — когда сформирован и какая задача.

**Шаг 3. Немецкие войска по разведке советских штабов**:
- разведывательные сводки 1 БФ и 1 УФ на 10–12.01: исходная группировка противника — какие
  дивизии, где, численность, танки, орудия;
- сводки за 13–25.01: резервы (19-я и 25-я танковые, корпус «Великая Германия»), где и когда
  появились;
- схемы группировки противника из раздела «Карты»;
- то же из разведсводок армий для участков 5 УА, 8 гв. А, 69 А, 33 А (Магнушев, Пулавы) и
  13 А, 52 А, 3 гв. А, 5 гв. А (Сандомир).

**Шаг 4. Горючее и боеприпасы танковых армий**: донесения и отчёты тыла 1 гв. ТА, 2 гв. ТА, 3 гв.
ТА, 4 ТА и тыла фронтов — наличие заправок и боекомплектов по дням, когда и где кончилось горючее,
сколько шло подвоза. Отдельно — отчёты о проведённой операции: в них часто есть итоговые таблицы.

**Шаг 5. Берлинская операция**, 16.04–02.05.1945, журналы боевых действий и оперативные сводки:
- 1 БФ: 47 А, 61 А, 3 УА, 5 УА, 8 гв. А, 33 А, 69 А, 3 А, 1 гв. ТА, 2 гв. ТА;
- 1 УФ: 3 гв. А, 13 А, 5 гв. А, 52 А, 28 А, 3 гв. ТА, 4 гв. ТА;
- по возможности 2 БФ: 65 А, 70 А, 49 А, 2 уд. А, 19 А.

Котёл 9-й армии (Хальбе, 24.04–01.05): журналы 3 А, 33 А, 69 А, 28 А, 3 гв. А — где стояли части
кольца и где был прорыв.

**Шаг 6. Познань**, 22.01–23.02.1945: журналы 29 гв. ск, 91 ск, 8 гв. А, 69 А, 1 гв. ТА —
- когда город окружён и кем;
- оценки численности гарнизона по разведке;
- ход штурма по дням.

## Структура вывода

Все файлы — JSON, кодировка UTF-8, в папке `tsamo-out/` (передать пользователю целиком).

### `positions-vistula-oder.json`, `positions-berlin.json` — положения

Та же схема, что у первой выборки (`docs/sources/vistula-oder-1945-tsamo.json`), — массив записей:

```json
{
  "army": "4 ТА",
  "date": "1945-01-18",
  "time": "19.00",
  "kind": "главные силы | передовой отряд | КП",
  "unit": "армия | 10 гв. тк | …",
  "place": "рубеж или пункт (короткий пересказ)",
  "lat": 51.25, "lon": 19.78, "approxKm": 5,
  "action": "прорыв полосы | бой за переправу | бой в городе | бой в лесу | преследование | марш | оборона | перегруппировка | резерв",
  "source": "ЦАМО, ф. …, оп. …, д. …, л. …",
  "url": "https://pamyat-naroda.ru/documents/view/?id=…",
  "note": "как геокодировано, что неясно"
}
```

`unit: "армия"` — положение армии в целом. Если в документе только корпуса, давать корпуса, а
положение армии не выводить самому. `action` — только из этого перечня; несколько — через `; `.

### `orders-vistula-oder.json` (и `orders-berlin.json`) — задачи

```json
{
  "to": "4 ТА",
  "from": "1 УФ | Ставка | 4 ТА",
  "issued": "1945-01-17T03:00",
  "received": "1945-01-17T08:00",
  "task": "наступать | марш | сосредоточиться | оборонять | выделить | …",
  "target": "куда / к какому сроку (пересказ)",
  "lat": 51.54, "lon": 16.45, "approxKm": 10,
  "deadline": "1945-01-22",
  "quote": "до 25 слов, если нужна",
  "source": "ЦАМО, ф. …, оп. …, д. …, л. …",
  "url": "…",
  "note": "номер документа, кто подписал, если есть"
}
```

`issued` — время подписания, если указано. `received` — время получения войсками, если оно есть в
журнале. Неизвестное — `null`. Если задача известна только из журнала («по приказу фронта с утра
20.01 марш…»), её тоже записывать: `issued` — `null`, срок начала исполнения — в `note`.

### `enemy-vistula-oder.json` (и `enemy-berlin.json`) — немецкие войска по разведке

```json
{
  "date": "1945-01-12",
  "formation": "6 пд | 19 тд | 17 А (штаб) | боевая группа …",
  "german": "6. Infanterie-Division (если указано)",
  "personnel": 6000, "tanks": 12, "guns": 60,
  "strengthNote": "как получена цифра: «до 6000», «полк по 600–700», «в ротах по 60–80»",
  "place": "участок или район (пересказ)",
  "lat": 51.6, "lon": 21.3, "approxKm": 10,
  "against": "5 УА",
  "docType": "разведсводка | схема группировки | отчёт об операции | трофейный документ",
  "source": "ЦАМО, ф. …, оп. …, д. …, л. …",
  "url": "…",
  "note": ""
}
```

Числа не пересчитывать: что сказано («до 4000», «около полка»), то и вносить. Своя оценка — только
в `strengthNote`, с пометкой «оценка агента».

### `supply.json` — горючее и боеприпасы

```json
{
  "army": "2 гв. ТА",
  "date": "1945-01-30",
  "fuel": 0.3, "ammo": 1.2,
  "units": "заправки | бк | т",
  "event": "нет горючего | подвоз | норма расхода",
  "text": "пересказ: «во второй половине дня без горючего на достигнутых рубежах»",
  "distanceKm": 600,
  "source": "…", "url": "…", "note": ""
}
```

`distanceKm` — только если пройденный путь указан в документе.

### `manifest.json` — что просмотрено

```json
{
  "fond": "345", "opis": "5487", "delo": "385",
  "title": "Журнал боевых действий 8 гв. А",
  "dates": "1945-01-01 — 1945-02-28",
  "url": "…",
  "readSheets": "л. 80–110",
  "covers": ["positions", "orders"],
  "gaps": "нет суточных записей за 21–22.01",
  "downloaded": true
}
```

## Проверка перед сдачей

- У каждой записи есть `source` с листом и `url`.
- Даты внутри периода шага; дубли (тот же документ, та же армия и дата) — объединены.
- Для каждой армии шага 1 — сколько дней покрыто из 23; непокрытые дни перечислены в `manifest.json`.
- Координаты не выходят за театр (49,6–53,8° с. ш., 14,0–22,6° в. д. для Висло-Одерской) и не
  прыгают больше чем на 80 км за сутки у общевойсковой армии без объяснения в `note`.
- Короткая сводка для пользователя: что найдено по каждому шагу, чего на портале нет, какие вопросы
  остались (например, «к чему привязано положение армии в этом документе»).

## Что будет с данными

Положения войдут в историю сценариев (надёжность A) вместо менее надёжных записей. Задачи
(`orders`) — в приказы сценария с полем `basis`. Немецкие войска — в численность и положение
немецких дивизий. Горючее — в норматив расхода. После каждого пакета модель будет пересчитана и
сверена заново.
