# Комплект переноса приложения

Целевой сценарий: перенести комплект с флешки на локальный диск, открыть приложение, установить LM Studio,
скачать и выбрать совместимые LLM и embeddings. В автономном комплекте Python, Node, FFmpeg,
модели голоса и библиотека не требуют ручной установки.

Для существующего Windows-комплекта доступно автономное обновление `release/defops-gpu-handoff`:
NF4 через PyTorch/bitsandbytes, проверяемый Flash Attention, поочерёдная загрузка LLM/TTS и
независимые переключатели комментариев и итогового разбора в меню оператора.
Оно содержит собственные wheels и проверяет CUDA-синтез до активации нового профиля, с резервной
копией и откатом. Необходимости пересобирать исполняемый файл нет. Порядок работы и ограничения
описаны в [руководстве Windows](expo-windows-offline.md#управляемый-профиль-nf4-и-flash-attention).

Поверх установленного GPU-профиля применяется `release/defops-tts-batch.zip`: температура голоса,
пакеты по 1/2/4 фразы итогового разбора, процент готовности и фотографии с полными подписями.
Обновление использует текущие зависимости и веса; короткая проверка настоящего CUDA-пакета
выполняется автоматически до изменения файлов. Подробности — в разделе
[«Температура и пакетная озвучка итогов»](expo-windows-offline.md#температура-и-пакетная-озвучка-итогов).

## Подготовленные компоненты

- macOS Apple Silicon, macOS 14 и новее: приложение Tauri, официальный Node 22, отдельный Python 3.12,
  MLX, статический FFmpeg, локальные qwen3-ru-stress, GigaAM, Smart Turn и VAD. Intel Mac не поддерживается.
- Библиотека: встроенная база знаний и экспорт всех 19 пользовательских хранилищ IndexedDB,
  карточки и сценарии, 287 предзаписей, образцы трёх голосов, словарь и подсказки, пять локальных карт.
- Пользовательский архив содержит 2226 записей: запись базы знаний, два закрепления, 2220 векторов и три правки.
  Это фактический состав текущего профиля, а не число встроенных фактов базы.
- Манифесты SHA256 и размеров файлов. До первого запуска голоса проверяется его runtime;
  библиотека проверяется до импорта. Пользовательские изменения при повторном импорте сохраняются.
- Встроенный мастер моделей, словаря и переноса библиотеки. Основная и голосовая LLM проверяются запросами
  генерации текста, embeddings — запросом числового вектора. Кэш поиска разделён по модели и размерности.
- Исходники и сценарий Windows-сборки: [expo-portable-windows-build.md](expo-portable-windows-build.md).
  Веса Windows и 110 проверенных wheels подготовлены отдельно от MLX. В переносимом наборе
  `BUILD-WINDOWS.cmd` запускает сборку с подготовкой инструментов и журналом. Сборка Windows/CUDA
  и проверка на целевой машине ещё не выполнены.

## macOS: подготовка и проверка

На машине сборки нужны подготовленное `services/voice/.venv`, кэш закреплённых моделей, Rust и npm-зависимости.
Конечному пользователю они не нужны. Выгрузка пользовательского слоя — в приложении, «ИИ → Модели, словарь
и перенос библиотеки → Библиотека». Режим экспорта переносит двоичные страницы и типизированные векторы;
обычная старая выгрузка «мои материалы» неполна для автономного комплекта.

```bash
npm run portable:mac -- --data "<папка данных приложения>" --archive "<user-library.json>"
```

Сборщик готовит runtime, библиотеку, каталог слов, лицензии и `.app`. При повторной сборке заменяются только
производные каталоги, не исходные пользовательские данные. Для отдельной тестовой папки данных приложение
принимает абсолютный `DEFOPS_DATA_DIR`; обычный запуск использует стандартную папку приложения.

Проверено локально: сборка `.app`; глубокая проверка ad-hoc-подписи; целостность runtime после упаковки;
запуск собранных Node-сервисов без Homebrew в PATH и с пустым HOME; импорт настоящего архива в чистую базу;
работа API словаря и каталога карт. Отдельно перенесённый Python синтезировал и распознал фразу с запрещёнными
сетевыми соединениями, пустым HOME и путём с пробелами и кириллицей.

Полная приёмка не завершена: просмотр нативного окна был ограничен блокировкой экрана Mac;
чистый физический Mac и три телевизора не проверены. В общем прогоне остаются два ранее выявленных падения
`expo-turns.test.ts` — ожидание, что промедление всегда ухудшает суммарную оценку; упаковка модель не меняет.
Остальные выявленные устаревшие проверки интро и словаря исправлены и прошли целевые прогоны.
Поэтому пакет следует считать технической сборкой для приёмки, а не подтверждённым выставочным релизом.

## Первый запуск на другом компьютере

1. Скопировать архив на локальный диск и распаковать. Не запускать с медленной флешки.
2. Открыть приложение. Дождаться проверки ресурсов и импорта библиотеки; первый старт дольше последующих.
3. Заранее установить LM Studio, загрузить подходящие модели, включить локальный сервер.
4. Выбрать модели в мастере и нажать «Проверить и сохранить». Убедиться, что приложение получает настоящие ответы.
5. Подключить три независимых дисплея, включить расширенный рабочий стол, назначить роли экранов в меню оператора.
6. Отключить сеть и пройти интро и оба фронта до итогов, проверить речь, возврат отключённого телевизора и масштаб.

При занятом сохранённом порте приложение сообщает причину и не открывает пустой профиль на случайном адресе.
Секреты, назначения мониторов, настройки LLM, журналы и счётчики прежнего компьютера не переносятся.
Записи словаря хранятся отдельно от ресурсов приложения. Они влияют на новую озвучку; готовые записи требуют
переозвучки. Наличие файлов тайлов не подтверждает полноту покрытия каждого нужного масштаба — это проверяют на карте.

## Границы комплекта

«Любой компьютер» означает поддерживаемую ОС, архитектуру и достаточные ресурсы. Windows 10 / RTX 4060 Ti 16 ГБ
требует проверки CUDA на реальной машине; объём RAM ещё не известен. Windows-папка с исходниками и весами
не является готовой программой. Полный Windows-runtime требует сборки и реального голосового теста x64.
Стартовый сценарий создаёт приёмочную сборку: известные два падения оценки промедления явно
сохраняются в её отчёте; любые иные падения блокируют сборку. Это не подтверждённый выставочный релиз.
Обычный HDMI-сплиттер дублирует изображение и не создаёт три независимых экрана.

macOS-сборка подписана локально ad-hoc, без Developer ID и нотариализации: проверка подписи подтверждает целостность,
а не доверие Gatekeeper на другом Mac. Внутри сохранены тексты лицензий и перечни зависимостей; условия распространения
FFmpeg, моделей, готовых аудио и голосовых образцов требуют отдельной проверки владельцем перед внешней раздачей.

Флешка должна поддерживать файлы больше 4 ГБ, например exFAT; ZIP сохраняет структуру и права приложения при переносе.
Форматы пакетов: [Tauri macOS](https://v2.tauri.app/distribute/macos-application-bundle/),
[Tauri Windows](https://v2.tauri.app/distribute/windows-installer/).
