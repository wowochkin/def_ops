# Шаблон таблицы фактов

Таблица (CSV или XLSX) и JSON-пакет внешнего агента имеют одни и те же столбцы. Каждая строка — один факт. Образцы:
`apps/editor/public/samples/facts-template.csv` и `facts-template.json` (значения в них вымышленные).

CSV: разделитель «,» или «;», кодировка UTF-8 или Windows-1251, десятичная запятая допустима (`12,5`). XLSX: берётся первый
лист, первая строка — заголовок. Даты — `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`; пустые ячейки допустимы.
Числа людей, техники и потерь — целые: разряды («52.000», «1 200») понимаются, дробное («450,5») — ошибка строки;
десятичная запятая допустима только в `lat`, `lon`, `approx_km`. Если есть столбец `kind`, пустой или неизвестный вид — ошибка строки.
Строка с ошибкой (дата — не дата, число — не число, не хватает обязательного) в базу не идёт: загрузка показывает номер
строки (заголовок — строка 1) и причину.

## Столбцы

| Столбец | Что в нём | Пример |
|---|---|---|
| `kind` | вид факта: `strength` — численность на дату, `reinforce` — пополнение, `losses` — потери за период, `parent` — подчинённость, `enter` — ввод в бой, `position` — положение, `boundary` — разграничительная линия, `crossing` — переправа, `event` — событие | `strength` |
| `subject` | соединение, часть или объект — как в источнике; для `boundary` — две стороны через «/» | `Условная 1-я армия` |
| `date` | дата или начало периода (обязательна) | `16.04.1945` |
| `date_to` | конец периода (для потерь и линий); пусто — тот же день | `18.04.1945` |
| `personnel`, `tanks`, `guns` | людей, танков, орудий (для `strength`, `reinforce`; `tanks` также в потерях) | `52000` |
| `killed`, `wounded`, `missing`, `total` | убито, ранено, пропало, всего потерь людьми (для `losses`) | `1800` |
| `parent` | вышестоящее соединение (для `parent`) | `Условная 1-я армия` |
| `place` | населённый пункт; для `boundary` — точки линии через «\|» | `Условные Холмы` |
| `lat`, `lon` | координаты положения, градусы | `52,45` / `14,60` |
| `approx_km` | неточность положения, км | `12,5` |
| `source` | название документа-источника; вместе с `pages` идёт в место источника | `Журнал боевых действий` |
| `pages` | лист, страница | `л. 12` |
| `reliability` | достоверность `A`, `B`, `C`; пусто — как у документа | `A` |
| `quote` | цитата из источника, на которой основан факт | `в армии 52000 человек` |
| `note` | пояснение; для `crossing` — состояние (`open`, `destroyed`, `built` или «проходима», «разрушена», «наведена»); для `event` — название события | `наведена` |

## Что обязательно по видам

- `strength`, `reinforce`: `subject`, `date`, хотя бы одно из `personnel`, `tanks`, `guns`.
- `losses`: `subject`, `date`, `date_to`, хотя бы одно число потерь.
- `parent`: `subject`, `date`, `parent`. `enter`, `position`: `subject`, `date` (положению — `place` или обе координаты `lat` и `lon`).
- `crossing`: `subject`, `date`, состояние в `note`. `event`: `date`, название в `note` (иначе берётся `quote`).
- `boundary`: две стороны в `subject`, `date`, не меньше двух точек в `place` через «|».

## Таблица не по шаблону

Если в первой строке нет столбцов `kind`, `subject`, `date`, модель предлагает смысл каждого столбца и вид фактов; предложение
подтверждается или правится в окне сопоставления. Заголовки-даты (`Соединение;16.04.1945;17.04.1945`) означают «дни в
столбцах»: каждая непустая ячейка — отдельный факт на день столбца.

## JSON-пакет агента

```json
{ "format": "def-ops-facts", "version": 1,
  "source": { "title": "…", "ref": "…", "reliability": "B" },
  "facts": [ { "kind": "strength", "subject": "…", "date": "1945-04-16", "personnel": 52000, "ref": "фонд, опись, дело, лист", "quote": "…" } ] }
```

Факты — те же поля, что столбцы; числа можно писать числами. Для удобства принимаются естественные ключи:
`state` (состояние переправы), `title` (название события), `between` (`["A", "B"]` — стороны разграничительной линии),
`points` (`["…", "…"]` — точки линии), `dateTo` (то же, что `date_to`). В таблице стороны линии пишут в `subject` через «/»
или «|». Состояние переправы — `open`, `destroyed`, `built` или по-русски: «проходима», «цел», «действует»; «разрушена»,
«взорван», «уничтожен»; «наведена», «наведён», «построен». Если у факта есть `ref` (шифр архивного документа или ссылка) или
он задан в `source.ref` пакета, подтверждение — выписка агента с этим шифром; без `ref` факт идёт как строка таблицы.
`source.title` попадает в место источника, если у факта нет своего `source`. `source.reliability` — достоверность по
умолчанию для фактов пакета. Иной `format` — ошибка «не формат def-ops-facts».
