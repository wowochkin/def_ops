# Ассистент модели в «Моделировании»

## Цель

Собеседник по технической стороне модели: как считаются бой, темп, подвоз, как устроены агенты, что такое
формула Дюпюи и откуда в ней коэффициенты. Отвечает по описанию модели (часть II `docs/system.md`), нормативам
(`packages/sim/data/rules/norms.json`) и исходному коду модели, со ссылками на раздел, норматив, файл и функцию.

## Решения, принятые с заказчиком

| Вопрос | Решение |
|---|---|
| О чём спрашивают | Устройство модели — техника расчёта и агентов |
| На что опирается | Описание (часть II), нормативы и исходный код модели |
| Подход | Поиск по заранее собранной выжимке; модель отвечает только по найденным фрагментам; один дозапрос по точному имени |

## 1. Выжимка

Команда `npm run model:index` (инструмент `packages/knowledge/tools/build_model_index.ts`) собирает
`packages/knowledge/data/model-index.json`:

```ts
interface ModelFragment {
  id: string;                    // doc:22.4#2, norm:<id>, code:packages/sim/src/combat.ts#resolveCombat
  kind: 'doc' | 'norm' | 'code';
  title: string;                 // путь заголовков / название норматива / имя функции
  place: string;                 // «раздел 22.4» / id норматива / файл:строка
  text: string;
  refs?: string[];               // для doc: имена функций и файлов, упомянутых в тексте (`step.ts`, `combatPower`)
}
```

- **Описание**: часть II `docs/system.md` (от заголовка «Часть II»), один фрагмент — подраздел с путём
  заголовков; длиннее ~2500 знаков — по абзацам, заголовок повторяется; таблицы целиком; строки-изображения
  и подписи курсивом под ними пропускаются.
- **Нормативы**: одна строка `norms.json` — фрагмент: что задаёт, значение, источник или «допущение», где
  используется.
- **Код**: `packages/sim/src/**/*.ts` — экспортируемые и внутренние функции верхнего уровня и экспортируемые
  константы с комментарием над ними; `crates/agents-core/src/**/*.rs` — `fn` (в том числе в `impl`) с
  комментариями `///`, структуры и перечисления с полями. Тело длиннее 80 строк обрезается («… строки N–M»).
  Тесты (`#[cfg(test)]`, `tests/`) не берутся.
- **Свежесть**: тест пересобирает выжимку в памяти и сравнивает с файлом.

## 2. Поиск и ответ

- Индекс — тот же, что у базы знаний (`packages/knowledge/src/search.ts`), над текстом фрагментов
  (заголовок + текст); по смыслу — через эмбеддинги базы знаний, если модель эмбеддингов есть.
- Два хода: (1) до 6 фрагментов описания и нормативов по вопросу; (2) до 6 фрагментов кода — функции из
  `refs` найденных разделов и найденные по вопросу. Общий объём — не больше ~24 000 знаков.
- Запрос модели роли «база знаний» (`kbLlm`): вопрос, фрагменты под номерами, последние 3 пары разговора.
  Правила: только по фрагментам, ссылки [n], формулы — простой записью с пояснением множителей и их значений,
  нет ответа во фрагментах — сказать.
- Дозапрос: ответ модели может начинаться строкой `НУЖНО: <имя>[, <имя>]` (функция, раздел «22.3», норматив
  id); фрагменты добираются по точному имени (не больше 4), следует окончательный ответ. Один раз.
- Поток: ход («ищу…», «дозапрос: …», «пишет ответ»), размышления, ответ; «Стоп».
- Сервер недоступен — сообщение; найденные фрагменты показываются.

## 3. Интерфейс

«Моделирование» → вкладка «Ассистент»: слева разговор (поле вопроса, лента, готовые вопросы над пустой
лентой, кликабельные ссылки [n]), справа источники ответа (раздел — номер, заголовок, текст; норматив —
значение, источник/допущение; код — файл, строка, функция, моноширинный текст; пометка «дозапрос»), сверху —
«найдено: N разделов, M нормативов, K функций»; «Новый разговор», «Стоп». Разговор (последние 20 пар) — в
`localStorage` этого браузера.

## Проверка

Тесты: нарезка описания (подразделы, таблицы, длинные разделы, пропуск изображений), нормативов, TS- и
Rust-функций (комментарии, обрезка, без тестов); поиск в два хода; дозапрос по имени; свежесть выжимки; ответ на
записанных ответах модели. Снимок вкладки; описание (часть I, «Моделирование»); `docs:system`; в CLAUDE.md —
пересборка выжимки после правок кода модели или части II.

## Вне задачи

Разбор конкретного прогона («почему армия отстала») и предложения правок модели.
