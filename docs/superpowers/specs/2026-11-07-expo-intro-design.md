# Выставочный режим: интро сеанса

## Цель

Перед выбором фронта посетитель видит визитную карточку системы. Это не заставка. Заставка остаётся. Касание играющей заставки открывает сеанс, и тогда запускается интро. Речь заранее записана. Картина — отдельная трёхмерная сцена, не интерфейс стенда.

## Решения

| Вопрос | Решение |
|---|---|
| Место | После касания заставки, до выбора фронта |
| Уход | Сам, когда предзаписанная речь доиграла. Нет клипов — картина идёт отмеренный срок и сама открывает выбор фронта |
| Пропуск | Кнопка «Пропустить» только внизу центра. Касание по картине интро не пропускает |
| Подпись | Текущая фраза и почта видны на всех трёх экранах |
| Речь | Заготовки в `berlin-1945.lines.json`, клипы командой `npm run expo:prepare`. Живой синтез в интро не используется |
| Картина | Three.js только на время интро, затем сцена уничтожается |
| Экраны | Центр — кино и речь. Боковые — разные амбиентные циклы. На всех трёх одна фаза |
| ИИ | Сквозная линия в речи и на всех трёх экранах, не отдельный слайд |
| Выключатель | Пункт меню оператора, по умолчанию включено. Действует со следующего сеанса |

## 1. Ход

1. Заставка играет, как сейчас.
2. Касание заставки при включённом интро глушит речь заставки сразу, переводит сеанс в фазу интро и запускает речь интро. Две речи не звучат вместе.
3. Касание заставки при выключенном интро сразу открывает выбор фронта. Трёхмерной сцены нет.
4. Интро кончается вместе с последним клипом речи либо по «Пропустить». Если клипов нет, центральная сцена всё равно играет и по истечении срока сама открывает выбор фронта. Все три экрана переходят вместе.
5. Смена выключателя во время уже идущего интро его не обрывает.

## 2. Речь

Четыре короткие фразы подряд, без подстановок, один клип на фразу. Голос тот же, что у остальных заготовок стенда. Перечень факторов голос не зачитывает: его показывает решётка слева. ИИ проходит через все четыре фразы:

1. Система опирается на большие объёмы исторических данных, математическое и агентное моделирование и искусственный интеллект. Палантир оставляет разбор внутри системы. Эта система предъявляет факторы и варианты, а решение оставляет за человеком.
2. В бой заложено много факторов, среди них пространственные. ИИ разбирает их вместе.
3. ИИ помогает принять взвешенное решение по всестороннему разбору обстановки и проигрывает много вариантов, чтобы командующий выбрал итог.
4. Модель настроена на Берлинскую операцию по открытым данным и может масштабироваться, в том числе на современные условия и на данные, которые поступают сразу.

Почта в речь не входит.

## 3. Центр

Обычные панели, карточки, легенда и шапка стенда на время интро скрыты.

Камера идёт над рельефом театра от Одера к Берлину. В первую секунду в темноте держится тёмный камень со светом внутри — намёк на Палантир, без знака и без названия на экране. Камень раскрывается в рельеф. Высоты берутся из данных модели, отдельный макет местности не рисуется. Сначала загораются реки и дороги, затем точки войск, затем сеть факторов. Впереди камеры тянется тонкая дуга вариантов. К концу речи из нескольких путей остаётся один. Это сквозная линия ИИ на центральном экране.

Крупный текст загорается в такт фразам. Это не слайды и не панель. Внизу на всех экранах постоянно видна почта `info@profdailog.ru`. Кнопка «Пропустить» только здесь.

## 4. Боковые экраны

Интерфейса стенда нет.

Слева течёт решётка факторов: местность, реки и дороги, снабжение, инженерные заграждения, погода, усталость войск, потери, время, ступени командования. Подписи загораются и гаснут. Отдельная нить «разбор ИИ» связывает те, что горят сейчас.

Справа рой точек. Они сходятся и расходятся. Часть роя отрывается, проходит несколько путей и сходится в один.

Оба цикла идут сами, пока длится интро. На каждом боковом экране внизу мелкой строкой видна та же фраза, которая сейчас звучит, и почта `info@profdailog.ru`. Кнопки пропуска там нет.

## 5. Меню оператора

Один выключатель: интро сеанса. Подпись поясняет, что это сцена после заставки, не сама заставка. Значение хранится вместе с остальными настройками стенда. По умолчанию включено. Если в сохранённых настройках поля нет, оно считается включённым.

## 6. Вне объёма

Заставка, выбор фронта, карточки решений и расчёт хода не меняются. Интро не заменяет речь заставки. Отдельный игровой движок и заранее снятое видео не используются.
