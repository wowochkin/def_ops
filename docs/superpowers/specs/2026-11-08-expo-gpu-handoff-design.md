# Поочерёдная работа LLM и Qwen TTS на Windows

## Задача и согласованные ограничения

Выставочный режим Windows 10 / RTX 4060 Ti 16 ГБ работает автономно. Пользователь разрешил
выгружать модели между этапами, заменив прежнее требование постоянной загрузки обеих моделей.
Qwen — тот же `qwen3-ru-stress`, словарь и назначенные голоса сохраняются. Выбран вариант
4 бит без MLX: NF4 через bitsandbytes/PyTorch, вычисления BF16. Оригинальные веса сохраняются;
предусмотреть обратимый переход к 8 битам/BF16 при неудовлетворительном качестве.

Текст комментария каждого из трёх решений генерируется **только после завершения анимации карты**,
затем синтезируется и звучит полностью, затем сохраняется пауза чтения 2 с. Комментарий —
две короткие фразы, до 50 выходных токенов и 220 символов. Итоговый текст по-прежнему
алгоритмический. Вся его озвучка готовится на экране «Готовим итог» до открытия разбора.
Новых тайм-аутов синтеза, обрезания аудиокодов, ограничения текста итога или смены модели нет.

Прогрев TTS во время последней анимации несовместим с сохранённым поздним LLM-комментарием:
Bonsai ещё понадобится после карты. Поэтому TTS загружается/прогревается после ответа LLM;
после третьего комментария остаётся в памяти для итога, без повторной загрузки Bonsai.

## Владение видеопамятью

Один координатор в главном окне стенда; боковые экраны не управляют моделями.
Запросы перехода сериализуются. Перед загрузкой LLM завершить выгрузку TTS; перед загрузкой
TTS завершить выгрузку выбранной LLM и проверить отсутствие её экземпляра. Ошибка выгрузки
не разрешает загрузку конкурирующей модели. Отмена/новый сеанс не запускают запоздалую загрузку.

- Выбор решения: TTS выгружена, выбранная в основном разделе «ИИ» LLM заранее загружена.
- Анимация: новые инференсы LLM/TTS и GPU-переключения не запускаются.
- После анимации: выбранная LLM выдаёт комментарий; затем её конкретный экземпляр выгружается.
- TTS загружается, прогревается на назначенном голосе, синтезирует и произносит комментарий.
- После комментариев 1/2: TTS выгружается, LLM загружается для следующего выбора.
- После комментария 3: TTS остаётся загруженной; после паузы весь итог готовится на ней.
- При новом сеансе/выходе незавершённые переходы отменяются; работающий синтез нельзя
  выгрузить посередине. Последующий переход ждёт его завершения; не выдаёт фиктивную готовность.

Использовать native LM Studio REST API `/api/v1/models`, `/load`, `/unload` через существующий
`/llm/` proxy, на фактический LLM_URL (в проверяемом комплекте порт 1235). Разрешать только
выбранную основную `settings.model`, учитывать ключ модели/идентификатор экземпляра и aliases.
Не выгружать посторонние LLM и embeddings. Неподдерживаемый native API — явная ошибка режима
управления памятью, без молчаливой отправки запроса тяжёлой модели по умолчанию.

## Голосовая служба

Сервис и CPU-компоненты остаются запущенными. Управляется только GPU-модель TTS, не процесс
Python целиком. Добавить коррелированные команды загрузки/выгрузки с подтверждением состояния.
Все операции с весами проходят через существующий однопоточный executor синтеза. PCM-заготовки
не теряются при выгрузке весов; их воспроизведение не требует повторного синтеза. Живая речь
основной версии и студия сами обеспечивают загрузку TTS перед синтезом.

Windows с включённым управлением стартует с CPU-службой и отложенной загрузкой TTS;
Mac сохраняет прежний MLX-путь. Конфигурация Windows хранится отдельно от engine/stress/roles,
содержит quantization (`nf4`, `int8`, `bf16`), attention и managed flag. Явный режим NF4 не
подменяется молча BF16. Прогрев и кэш голосового промпта привязаны к образцу/mtime/тексту и
сбрасываются при выгрузке. Действующие `non_streaming_mode=True`, `repetition_penalty=1.5`,
температуры 0.2 сохраняются.

## Flash Attention и автономность

Проверить FA2 на точном стеке CPython 3.12 x64, Torch 2.7.1+cu128, Transformers 4.57.3.
Кандидат Windows wheel собран под Torch 2.7.0/cu128; совместимость patch ABI не предполагается,
а проверяется настоящим вызовом CUDA на целевой машине. До успешной проверки сохраняется SDPA.
В отчёте различать выбранный backend, доступность и реально выполненное ядро. Включение флага
без успешного вычисления не считается активацией. Ускорение оценивается по свежему замеру;
квантование и освобождение памяти сами по себе не гарантируют ускорения.

Обновление переносится на USB с wheels, лицензиями, SHA256 и проверкой перед установкой;
никаких обращений к сети или смены Torch/Transformers при установке. Резервные копии исходников,
настроек и manifest. До переключения на новый профиль — локальный CUDA smoke NF4/FA2 и WAV
для прослушивания; ошибка сохраняет прежний рабочий профиль. Готовый исполняемый файл не пересобирается.

## Понятное ожидание

Плашка внизу сохраняет широкую форму. Для итога показывать выполненные/все фрагменты и прошедшее
время; загрузка и прогрев объединены до подтверждения службы, затем отображается синтез. Не рисовать выдуманный процент или ETA.
Счётчик обнуляется при смене/отмене сеанса и синхронизируется с боковыми окнами.

## Проверка

Тесты граничных случаев: другая модель/alias, уже загруженная модель, неподдерживаемый API,
ошибка выгрузки, два параллельных клиента, отмена во время load, третий комментарий без bounce,
PCM после unload, ошибка NF4/FA2 без подмены профиля. Подтвердить отсутствие GPU-инференса во
время карты и ожидание всех фраз итога. UI — снимок 1440×900 JPEG. Обновить system.md/PDF/Word.
Тесты без CUDA не доказывают совместимость нативных wheels или скорость; эти результаты получать
на целевой Windows-машине и явно отличать от локальных проверок.
