# Исторический слой: болота по штриховке карты

## Цель

Болота на картах 1940-х — штриховка (короткие горизонтальные чёрточки синего, зелёного или чёрного цвета), а не
заливка, поэтому распознавание по цвету их не видит: образец «болото» даёт либо ничего (чёрточки тонкие), либо
воду и надписи того же цвета. На театрах болот мало (Берлинский — 51 клетка из ~67 тыс.), хотя в 1945 г. их было
больше (поймы Одера, Шпреевальд, Хафель, низины до осушения). Болото меняет бой (поправка обороны ~1,4–2,1) и темп
(0,5), поэтому пропуск влияет на расчёт.

Нужно: распознавать штриховку болот на подложенной карте, сверять с современными болотами (растр театра и OSM
`natural=wetland`), показывать сводку и предпросмотр и записывать болота в местность театра.

## Решения (приняты исполнителем без заказчика)

| Вопрос | Решение | Почему |
|---|---|---|
| Как узнавать штриховку | по «чернилам» (цвет образца или выученный цвет) + признаки окна: доля чернил разреженная (не заливка), чёрточки горизонтальные (средняя длина горизонтальной серии ≥ 2× вертикальной), повторяемость по вертикали | отличает болото от воды (заливка), надписей (нет направленности) и дорог (длинные линии) |
| Откуда цвет штриховки | 1) образец «болото» (как сейчас); 2) «по современной сети» — выучить по окнам внутри современных болот против окон вне их, как цвет дорог и воды | второй способ работает без ручных образцов |
| Современные болота | клетки «болото» растра театра + OSM `natural=wetland` (пути и мультиполигоны) | растр уже есть; OSM точнее по контурам |
| Что записывается | болото карты → клетка «болото» (поверх открытой местности и леса, не поверх воды и застройки); современное болото, которого нет на карте, — по выбору «убрать болота, которых нет на карте» (по умолчанию выключено) | в 1945 г. болот было больше; осушенное позже — главное, что нужно добавить |
| Граница тайлов | окно признаков с полями в соседние тайлы не берётся; клетка оценивается по сумме окон внутри тайлов | как `dropBlobs`, без склейки тайлов |
| Масштаб | окно признаков ≈ 120 м на местности (по метрам на пиксель уровня тайлов), не меньше 12 и не больше 48 пикселей | чёрточки разных карт 1:100 000–1:300 000 |

## 1. Признаки штриховки

`packages/sim/src/overlay-hatch.ts`:

```ts
interface HatchStats { ink: number; px: number; hRun: number; vRun: number; rows: number }
hatchWindow(cls: Int8Array, size: number, x0: number, y0: number, w: number, ink: number): HatchStats
isHatch(s: HatchStats, o?: { minInk?: number; maxInk?: number; aniso?: number }): boolean
```

- `ink` — доля пикселей класса «чернила болота» в окне; болото — `0,03 ≤ ink ≤ 0,40` (по умолчанию).
- `hRun`/`vRun` — средняя длина серий чернил по строкам и столбцам; болото — `hRun ≥ 2 · vRun` и `hRun ≥ 3` px.
- `rows` — число строк окна с чернилами; болото — не меньше трети строк окна покрыто чёрточками с шагом (не одна
  линия): `rows ≥ w / 6`.
- Окна, где `ink > maxInk`, — заливка (вода/надпись крупно), не болото.

`OverlayAccumulator.addTile`: для класса легенды `marsh` с признаком `hatch: true` пиксели считаются не напрямую,
а по окнам: окно-болото даёт клетке все свои пиксели как «болото». Порог клетки — 0,3 (как сейчас).

## 2. Болота по современной сети

`overlay-network.ts`:
- `osmNetworkQuery` дополняется `way/relation["natural"="wetland"]` (`out geom`); `osmToWetlands(json, box)` —
  полигоны (внешние кольца мультиполигонов, дыры — внутренние).
- `WetlandLearner`: окна внутри современных болот (клетки «болото» растра ∪ полигоны OSM) против окон вне болот и
  вне воды; цвет-бин учится, если он чаще внутри (порог как у воды) **и** окна с ним внутри проходят `isHatch`.
  Результат — образец `marsh` с `hatch: true` для второго прохода.
- `L.mergeMarsh` → маски `marsh-present` (современное и на карте), `marsh-new` (на карте, нет сейчас),
  `marsh-gone` (сейчас есть, на карте нет).

## 3. Запись в местность

`applyOverlay`: класс `marsh` — после воды и застройки, перед лесом (болото в лесу — болото); `marsh-gone` снимает
болото только при флажке «убрать болота, которых нет на карте» (клетка становится открытой или лесом по
соседям — как вода). Изменения считаются как сейчас («open→marsh»).

## 4. Интерфейс

«Карты → Театры → Исторический слой»:
- у образца «болото» — флажок «штриховка» (по умолчанию включён);
- «по современной сети» проверяет дороги, воду и болота; «Загрузить из OSM» берёт и болота;
- сводка болот: узнанный цвет штриховки, клеток «на карте и сейчас / только на карте / только сейчас»;
- предпросмотр — клетки болот тремя оттенками;
- при сохранении — флажок «убрать болота, которых нет на карте».

## Проверка

Тесты на синтетических тайлах: штриховка (чёрточки 6×1 px с шагом 5 px) в прямоугольнике → болото; та же краска
сплошной заливкой → не болото; надпись тем же цветом → не болото; длинная горизонтальная линия (дорога) → не болото;
обучение цвета по современным болотам растра; разбор OSM-мультиполигона с дырой; запись в местность с приоритетом
(вода и застройка не перезаписываются, лес — да); флажок «убрать» снимает только при включении. Сквозной прогон на
театре `oder-berlin-1945` с синтетической подложкой. Описание (часть II, раздел 17.2 — абзац «Болота по
штриховке», строка «Болота … этим способом не распознаются» — убрать), снимок вкладки со сводкой болот, `model:index`
(часть II), `docs:system`; руководство пользователя — строка в разделе о подложках.

## Вне задачи

Другие узоры (кустарник, пески, вырубки); распознавание болот без образца и без современных данных.
