# Модули погоды и многослойной картографии

Статус: пользователь разрешил автономную реализацию полного объёма, включая конвертацию исходных геоданных.

## Назначение и согласованные требования

Общий экран «Карта и погода» объединяет два модуля: загрузка исторической погоды и собственная
симуляция погоды по времени сценария; загрузка картографических данных с независимыми
слоями. Пользователь уточнил: «в реальном времени» означает собственную симуляцию
сценария. Получение текущего прогноза не входит в обязательную первую реализацию.

Загруженные наборы должны работать без сети и переноситься между macOS и Windows.
Модули предоставляют данные; изменения расчёта боевого потенциала и правил боевых
действий не входят в эту доработку.

## Предлагаемые решения

Далее перечислены проектные решения, предложенные для согласования, а не уже
согласованные требования пользователя.

### Модуль погоды

Общий формат набора: идентификатор, географический охват, временной диапазон,
источник и его версия, лицензия, исходная пространственная и временная детализация,
единицы измерения, признаки пропусков и качества, контрольные суммы файлов.
Координаты — WGS84, время хранения — UTC; часовой пояс используется при отображении.
Различаются наблюдения, реанализ, интерполяция и синтетические значения.

Первый онлайн-коннектор — исторический API Open-Meteo с явным выбором ERA5.
Глобальный реанализ с 1940 года не объявляется наблюдением непосредственно в точке.
Для использования API в выставочном/коммерческом приложении проверяется подходящий
тариф; ключ хранится на сервере. Предусматривается импорт заранее подготовленного
CSV/JSON по опубликованной схеме без зависимости от этого сервиса.
Прямой коннектор Copernicus CDS и станционные архивы NOAA — последующие коннекторы;
первая версия не обещает универсальный парсер GRIB/NetCDF или всех архивов мира.
При отсутствии покрытия возвращается явное «нет данных», без подмены синтетикой.

Поля: температура, влажность, давление, ветер (скорость, направление и порывы),
облачность, тип и интенсивность осадков. Видимость, снежный покров, температура
и влажность грунта имеют отдельные признаки доступности: нельзя обещать их для
каждого источника. Показатели разных источников не смешиваются без записи происхождения.

Симулятор — воспроизводимый генератор сценарной погоды, не численный прогноз атмосферы.
Настраиваются начальное состояние, сезонный профиль, область, исходное зерно,
переходы погодных состояний и скорость сценарного времени. Пространственно связное
поле и плавные переходы исключают независимую случайную погоду в соседних точках.
Ограничения допустимых величин и согласованности осадков/температуры/влажности явные.
Нет неподтверждённого обещания моделировать реальные фронты, микроклимат или обледенение.
Можно задать ключевые состояния вручную или стартовать из загруженного архива.

Расчёт привязан к единому времени сценария, поддерживает паузу, ускорение,
сохранение и восстановление. Одинаковые параметры, версия генератора и зерно дают
одинаковый результат независимо от частоты кадров и числа открытых экранов.
Внешний API чтения — состояние по координатам и времени, плюс поле для отображения.

### Модуль картографии

Расширяется существующий services/cartography; MapLibre остаётся средством отображения.
Текущие XYZ, растровые архивы и историческая карта сохраняют прежние форматы и поведение.
Современные пакеты получают собственный тип источника и стиль, без переиспользования
схемы слоёв OpenHistoricalMap для несовместимых тайлов.

Базовые источники:

- готовые векторные MBTiles OpenFreeMap для локального обслуживания;
- региональные исходные данные OSM от Geofabrik, если готовый набор не содержит
  нужных объектов/атрибутов; это .osm.pbf, не готовый тайловый архив;
- Copernicus DEM GLO-30/GLO-90 для высот;
- ESA WorldCover для классов наземного покрова;
- пользовательские GeoJSON и XYZ/WMS/WMTS при разрешённом скачивании.

Одна поставка не покрывает все тематические слои. Каталог показывает фактически
обнаруженные слои, происхождение и отсутствующие данные, а не обещанный максимум.
Дороги, железные дороги, здания, вода, населённые пункты, границы, землепользование
и доступные объекты инфраструктуры переключаются независимо, если они присутствуют
в исходном векторном пакете. Рельеф и покров земли — отдельные наборы.
Высота здания, грузоподъёмность моста и прочие отсутствующие атрибуты не выдумываются.
DEM может содержать поверхность с сооружениями/растительностью; он не выдаётся
за гарантированно очищенную модель грунта.

Первая версия: импорт и локальная раздача готового современного MBTiles,
выбор области и масштабов при поддерживаемой выгрузке, управление слоями,
импорт стандартизованного GeoJSON, локальные стили, шрифты и значки.
Подготовка .osm.pbf, исходного GeoTIFF DEM/WorldCover и спутниковых сцен в тайлы —
отдельный этап конвертации с проверкой Windows; обещать его готовность вместе
с простым импортом MBTiles нельзя. PMTiles — дополнительный формат после MBTiles.

Публичный tile.openstreetmap.org не используется для массовой офлайн-загрузки.
Прямые загрузки с публичного OpenFreeMap ограничиваются его опубликованной политикой;
для больших районов используется предоставленный архив или собственный сервер.
Спутниковая подложка — отдельный источник с явным правом скачивания, не автоматическое
копирование Esri/Google. Лицензии исходных данных и атрибуция сохраняются в пакете.

Загрузка выполняется фоновой задачей: оценка объёма и свободного места, прогресс,
отмена, возобновление, ограничение запросов, проверка контрольных сумм.
Пакет становится доступным после проверки; сбой не повреждает действующую карту.
Поддерживаются пересечение антимеридиана, пределы широты Web Mercator и явное
сообщение о данных вне доступного масштаба. Погода может покрывать полюса независимо
от ограничения веб-карты.

## Интерфейс и приёмка

В современном рабочем пространстве доступны «Погода» и «Карты и слои».
Погода: режим архив/симуляция, область, дата/период, параметры, источник, локальные наборы.
Карта: каталог локальных пакетов, импорт/скачивание, область, масштабы, слои, лицензии.
Это служебные модули, не новые виды боевых сценариев.

Проверки: архивный ответ и пропуски; единицы/UTC; повторяемость симуляции при разных
шагах времени и после восстановления; независимость от экранов; локальная карта
с кириллицей и отдельными слоями при полностью выключенной сети; повреждённый архив,
отмена загрузки, нехватка места, нестандартные пути Windows; отсутствие регрессии
исторических карт. Работа на реальном Windows проверяется отдельно от тестов macOS.
Изменения сопровождаются docs/system.md, снимками 1440×900 JPEG и сборкой PDF/Word.

## Принятое решение

Пользователь поручил реализовать полный объём автономно. В реализацию включены
архив Open-Meteo, CSV/JSON, сценарный генератор, MBTiles, GeoJSON и преобразование
OSM PBF/XML и GeoTIFF DEM/WorldCover. Прямой CDS, универсальный GRIB/NetCDF и PMTiles
остаются отдельными дополнительными форматами согласно описанным границам.

Погодное поле отображается отдельным слоем. Пользователь выбирает рамку, шаг сетки и длительность сценария. Числовые высоты DEM корректируют сценарные температуру и давление. Для OSM, DEM и WorldCover доступен автоматический подбор файлов по области.
