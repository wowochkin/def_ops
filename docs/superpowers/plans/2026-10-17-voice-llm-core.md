# Голос: понимание свободных формулировок моделью (основа ступени 2) — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** реплику, которую правила не поняли, понимает языковая модель: выбирает доступное действие из реестра
или честно отвечает, что такого нет; отвечает коротко голосом начальника штаба.

**Architecture:** разборщик (`dispatch.ts`) — правила как быстрый путь; «не понял» → `voice/llm.ts`: запрос
OpenAI-совместимый с `tools` через `/llm/v1` (LM Studio, модель «Голос» из раздела «ИИ», без размышления);
инструменты — действия реестра, доступные сейчас; ответ модели — текстом в `say`, вызов — `act`. Повторы при
сбое — до трёх попыток.

**Tech Stack:** TypeScript, React, vitest, Playwright (поддельная LM Studio).

**Spec:** `docs/superpowers/specs/2026-10-17-voice-control-design.md`, разделы «Кто пользуется», 3 («Разбор
реплики» п. 3–5), 6.

## Global Constraints

- Русский язык; коммиты с двумя строками атрибуции сессии.
- Пользователи — люди старшего возраста и эксперты: ответы коротко (1–2 фразы), простыми словами, без цифр в
  тексте (числа словами), без технических слов; возможности не придумываются: только действия реестра; нет
  подходящего — «Этого система пока не предусматривает. Могу: …» (2–3 примера из реестра).
- Правила — первыми (мгновенно); модель — только когда правила дали «не понял» и реплика обращена к штабу
  (обращение или окно разговора 12 с).
- Модель: настройка `voiceModel`/`voiceThinking` в `LlmSettings` (раздел «ИИ», `ModelPicker` с `who='voice'`);
  пусто — как в «ИИ»; размышление по умолчанию выключено (`reasoning_effort: 'none'`).
- Сбой LM Studio (ошибка, пустой ответ, нет ответа 20 с): повтор сразу, через 1 с, через 3 с; со второй попытки —
  заготовленная фраза «Связь с моделью прервалась, повторяю запрос»; после третьей — «Связи с моделью нет».
- Необратимых действий на этой основе нет; механизм подтверждения — в ступени 2 (командование).
- Перед коммитом: `npm run typecheck`, `npm test`; при изменении окна — `node scripts/voice-e2e.mjs` (и `--no-stub`).

## Review Focus

- Модель вызывает несуществующее или недоступное действие — не исполняется, честный ответ (Task 1, тест).
- Модель отвечает длинно, с цифрами или англ. словами — текст для речи укорачивается/нормализуется (Task 1, тест).
- LM Studio не отвечает — три попытки, заготовленные фразы, правила продолжают работать (Task 1, тест).
- Ответ модели пришёл после того, как человек сказал новое — старый ответ не звучит (Task 2, тест/e2e).
- Пока модель думает, панель показывает «Думаю», а не висит (Task 2, e2e).

### Task 1: Модель за правилами

**Files:** create `apps/editor/src/voice/llm.ts`, `apps/editor/src/voice/speech.ts`; modify `dispatch.ts`,
`registry.ts` (схемы параметров → `tools`), `apps/editor/src/sim/game-protocol.ts` (`voiceModel`, `voiceThinking`),
`apps/editor/src/ModelPicker.tsx` (`who: 'voice'`); tests `apps/editor/tests/voice-llm.test.ts`,
`voice-dispatch.test.ts`.

**Interfaces:**
- Produces: `toTools(actions: Action[]) -> OpenAITool[]` (имя — id с заменой «.» на «__», описание — `describe`,
  параметры — `params` или пустой объект); `askModel(text: string, ctx: { actions: Action[]; settings: LlmSettings;
  history: { role: 'user' | 'assistant'; content: string }[]; fetch?: typeof fetch; signal?: AbortSignal; onRetry?:
  (n: number) => void }) -> Promise<{ say: string; call?: { id: string; params: unknown } }>`;
  `speakable(text: string) -> string` (числа словами по-русски, без сокращений; до 2 предложений / 300 знаков);
  `Dispatcher` получает опцию `model?: (text, actions) => Promise<…>` — вызывается на «не понял» (обращённое),
  исполняет `call` через `act` (проверка: действие есть и `available() === true`, иначе честный ответ), говорит `say`.
  Системный текст: роль начальника штаба, правила речи, список доступных действий с `say`-примерами и недоступных с
  причиной, запрет придумывать возможности.

- [ ] Тесты (поддельный `fetch`): свободная формулировка → вызов `shell.open {section:'replay'}` и ответ;
  вызов несуществующего/недоступного действия — не исполняется, ответ «пока не предусматривает» с примерами;
  ответ с цифрами «в 5 часов» → «в пять часов»; длинный ответ укорочен; сбой ×2 затем ответ — `onRetry` вызван,
  итог исполнен; сбой ×3 — «Связи с моделью нет»; правила по-прежнему срабатывают без вызова модели; модель не
  вызывается для необращённой реплики вне окна разговора.
- [ ] Реализация; проверки; коммит «Голос: свободные формулировки — модель за правилами».
