# Выставочный режим, этап 4 «Подача» — план

Спецификация: `docs/superpowers/specs/2026-10-30-expo-mode-design.md` (раздел 2, «Порядок работ» п. 4).

## Global Constraints

- Карта — из данных театра и истории сценария (реки, рубежи, населённые пункты, положения армий по дням) и из
  настоящего хода ядра сеанса (положения армий по кадру). Подложка готовится заранее командой и коммитится: окна стенда
  не грузят тайлы и не ждут ядра, чтобы показать заставку и ввод в обстановку.
- Анимация — CSS и `requestAnimationFrame`; при `prefers-reduced-motion` — сразу конечный кадр.
- Звук — только синтез WebAudio (никаких чужих записей); громкость и включение фона — из меню оператора.
- Тема `theme.css` (переменные `--expo-*`, текст не меньше 32 px), 1440×900 без переполнений.
- Отпечатки ядра не меняются; полный режим редактора не затронут.

### Task 1: Подложка карты

`scripts/expo-map.ts` (`npm run expo:map`) → `bank-data/berlin-1945.map.json`: рамка, большие реки (упрощённые),
укреплённые полосы, населённые пункты, положения армий по истории по суткам, события истории с точкой.
`expo/map.ts` — проекция, положения армий на момент (история — между сутками; ход ядра — среднее дивизий армии),
стрелки карточек. Тест: `apps/editor/tests/expo-map.test.ts`.

### Task 2: Карта в виде модели

`ModelView.map`: армии до и после прокрутки, новые события с точкой, след армий фронта по переломам; у карточки —
стрелки распоряжений. Тест: `apps/editor/tests/expo-session.test.ts`.

### Task 3: Сцены

`expo/ExpoMap.tsx` (SVG): заставка — ускоренная переигровка по истории с бегущей датой во всю ширину (на нескольких
экранах — части одной панорамы); выбор фронта — мини-карты со стрелкой задачи; ввод — камера от общего плана к полосе
фронта, армии по очереди, противник, рубежи, задача; перелом — стрелки раскрытой карточки; прокрутка — движение армий
и вспышки событий; итог — путь посетителя поверх исторического.

### Task 4: Звук

`expo/sound.ts`: фон штаба (далёкая канонада, телеграф) и событийные звуки (касание, выбор, последние 10 с таймера,
событие хода) по смене состояния режиссёра. Тест: `apps/editor/tests/expo-sound.test.ts` (какие звуки на какую смену, громкость).

### Task 5: Снимки и описание

`scripts/expo-shots.mjs` — сцены ввода и прокрутки; раздел 2.1 `docs/system.md`, PDF и Word.
