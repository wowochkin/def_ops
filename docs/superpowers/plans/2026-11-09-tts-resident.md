# Постоянная NF4 TTS — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans; независимые части по dispatching-parallel-agents.

**Goal:** постоянно прогретая NF4 TTS рядом с Bonsai, офлайн-проверка и патч Windows, без искусственной паузы после карты.
**Architecture:** существующий managed=false/NF4, кэш голосов и готовых PCM;2CPU-потока, текущий пакет1/2/4;
проверять реальные циклы/память/30с на Windows до переключения профиля.
**Tech Stack:** TypeScript/React, Python3.12/Torch2.7.1/qwen-tts0.1.1, локальный LM Studio REST.
**Spec:** docs/superpowers/specs/2026-11-09-tts-resident-design.md

## Global Constraints
- Порядок: карта → полный комментарий → подготовка всего алгоритмического разбора → показ результата.
- Цель30с не превращается в deadline; фразы не обрываются. Default batch4 сохраняется вне патча.
- Текущая dirty ветка и прежние исправления сохраняются; коммит/публикация не запрошены.
- Hardware-вердикт только из нативного Windows/CUDA-прогона, не из Mac-моков.

## Review Focus
- Пауза меню/нулевое время не вызывают ранний переход или пропуск аудио.
- Пакет8 проходит через настройки, клиент, сервер, все PCM готовы до результата.
- Bonsai неоднозначна/нет сети/нехватка VRAM — никаких подмен моделей и изменений приложения.
- Ошибка замены/прерванный или повторный откат возвращают согласованные файлы и манифесты.
- Цель30с не достигнута — отчёт честно показывает измеренное время, постоянное размещение оценивается отдельно.
