# Выставочный режим: замечания после просмотра (1 ноября)

Каждый пункт — задача; при раскладке на 2–3 экрана у каждого экрана своё содержание, дублей нет.

1. **Заставка (до принятия командования).**
   - Фото «Встреча на Эльбе» обрезано по лицам — кадрировать по лицам (object-position по манифесту картинки).
   - Диктор молчит — на заставке голос говорит по кругу (предзапись: призыв, коротко о стенде и ИИ, с паузами
     между фразами; подход посетителя определить нечем). На заставке — заметная кнопка «Голос: вкл/выкл»
     (состояние запоминается до перезапуска стенда, оператор задаёт значение по умолчанию в меню).
   - Экраны 1 и 3 дублируют карту. Должно привлекать и рассказывать про искусственный интеллект и основное
     приложение: экран «Как работает штаб ИИ» (модель, база знаний — число источников, ядро переигровки,
     голос), экран переигровки на карте, экран «Полная версия» (что умеет основное приложение — снимки
     экранов из docs/img, рекорды дня).
2. **Ввод в обстановку.** Одни и те же данные на трёх экранах — разнести: карта с кадром пункта / пункт доклада
   крупными цифрами / справка-экскурс с архивным кадром. Голос молчит — озвучить пункты доклада. Экскурс —
   по документу `~/Downloads/7_Берлинская_наступательная_операция_16_04_08_05_1945_г_карта,_описание.pdf`
   (3 страницы: цель, силы трёх фронтов, Одерско-Нейсенский рубеж 20–40 км, три обвода Берлина, замыслы
   сторон, ход по этапам): только факты и короткие пересказы своими словами с указанием источника, текст
   документа в репозиторий не кладётся.
3. **«Штаб ИИ» (экран 1 на переломе) не функционален** — текст поверх фона. Нужна рабочая панель ИИ: готовые
   вопросы кнопками и ответ с источником, разбор обстановки моделью (соотношение сил, что важно на этом
   переломе — без подсказки исхода), видно, как ИИ работает: какие источники базы знаний взяты, что считает
   ядро, состояние голоса («слушаю», «отвечаю»).
4. **Обстановка после хода** — без полезной информации и дублируется на экранах 1 и 2. Нужна сводка изменений
   за ход: продвижение (км, взятые пункты, форсирования), потери, реакция противника, сравнение с историей
   на ту же дату; на каждом экране своё.
5. **Карточки.** Знак армии и мини-карта стрелок избыточны — заменить фотографией (архивный снимок
   общественного достояния по теме карточки: командующий, место, техника; с подписью и источником).
   Сейчас фото подставляются невпопад: `photoFor` ищет слова темы в тексте, не нашёл — ставит один и тот
   же берлинский кадр июня 1945 на все карточки фронта. На переломе «Зееловские высоты, 16 апреля» две
   карточки из трёх показывают Жукова с союзниками в Берлине 5 июня, третья — колонну в американском
   секторе в июле. Так нельзя. У каждой карточки банка — своё поле `photo` (файл из манифеста), подобранное
   по месту, действию и дате решения, а не по случайному совпадению слов. На одном переломе фото не
   повторяются. Нет подходящего снимка — карточка без фото, а не чужой кадр. Подпись под фото — что на
   нём и когда, чтобы не выдавать июнь за 16 апреля.
   Недостающие кадры присылает пользователь, сами «похожие» не подставляем. Пока нет подписи
   и источника, файлы в репозиторий не класть. Уже прислано (подписи — пакетом в конце):

     «Ночной штурм с прожекторами»;
