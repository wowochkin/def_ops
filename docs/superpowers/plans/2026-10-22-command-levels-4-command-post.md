# Командование по ступеням — этап 3б: пункт управления по уровням. План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Панель управления в игре на агентной модели зависит от уровня: на уровне «Ставка» — пункт управления
Ставки (директивы фронтам), «Фронт» — штаба фронта (директивы армиям), «Армия» — штаба армии (боевые приказы
корпусам), «Корпус» — штаба корпуса (боевые приказы дивизиям), «Дивизия» — боевые распоряжения дивизиям. У каждой
формы — свои поля по разделу 1 спецификации; рубежи, ось главного удара и разграничительные линии указываются на
карте.

**Architecture:** Директива игрока с полной структурой уходит в ядро командой управления `directive` (в очереди хода,
в записи игры). Отдающий — штаб пункта управления: взятый игроком штаб ступени или верхняя инстанция (тогда получатель
ниже фронта — через голову). Чистые функции панели — `apps/editor/src/command-post.ts`; компонент —
`apps/editor/src/CommandPost.tsx`; уровень карты и пункт управления переключаются вместе.

**Spec:** `docs/superpowers/specs/2026-10-21-command-levels-design.md` (разделы 1, 4, 5)

## Global Constraints

- Язык интерфейса — русский; «как сейчас» (Legacy) и нынешняя модель — без изменений (прежняя панель «Войска»).
- Работа — в ветке `claude/desktop-app`.

## Формы по ступени получателя (раздел 1 спецификации)

| Пункт (уровень) | Получатели | Документ | Поля |
|---|---|---|---|
| Ставка | фронты | директива Ставки | задача, цель (пункт), ось главного удара, армии главного удара, ближайшая задача (рубеж, срок), последующая (рубеж, срок), разграничительные линии (правая, левая), ответственный за стык, резервы Ставки в состав |
| Фронт | армии фронта | директива фронта | задача, полоса (разграничительные линии), участок прорыва (рубеж ближайшей задачи), задача на глубину (последующий рубеж, срок), ввод подвижной группы (танковой армии) |
| Армия | корпуса армии | боевой приказ армии | задача, полоса, эшелон (первый / второй), ближайшая и последующая задачи |
| Корпус | дивизии корпуса | боевой приказ корпуса | задача, полоса, ближайшая задача и задачи в глубине, направление дальнейшего наступления (ось) |
| Дивизия | дивизии | боевое распоряжение | задача, рубеж или пункт |

Любой пункт может отдать вместо приказа боевое распоряжение (быстро, слаженность ниже).

### Task 1: Ядро — директива с полной структурой и отдающим штабом
- `PlayerDirective`: `from?: String` (штаб пункта; нет — верхняя инстанция), `boundaries: Vec<{ neighbour?: String, line: Vec<LngLat> }>`,
  `main_blow: Vec<String>`, `reserve: Vec<String>`, `junction?: String`, `immediate_by?: u32`, `subsequent_by?: u32` (час операции),
  `echelon?: "first"|"second"`, `commit?: bool` (ввод подвижной группы).
- Отдающий: верхняя инстанция или штаб стороны игрока под управлением игрока (`Control::Player`); иначе — ошибка.
  Через голову — получатель не прямой подчинённый отдающего.
- `echelon` — роль получателя (первый, второй эшелон) с исходным положением; `commit` — роль «введена».
- `CommandOp::Directive { directive }`.
- Тесты (`tests/game.rs`): `directive_from_taken_army_to_corps` (армия взята — приказ корпусу от армии, не через голову,
  без извещений), `directive_from_agent_hq_rejected`, `directive_full_fields` (главный удар, границы, сроки дошли
  до замысла получателя), `directive_echelon_and_commit` (роли), `command_op_directive` (через `command_json`).

### Task 2: Чистые функции пункта управления
`command-post.ts`: `postOf(level)`; `issuers(v, level)` (штабы ступени над получателями: Ставка; фронты; армии; корпуса);
`recipients(v, issuer, level)`; `formFields(level)`; `postTitle`; `toDirective(draft, v)` → JSON `PlayerDirective`;
`describeDraft`. Тесты `command-post.test.ts` — по одному на каждую ступень и на «через голову».

### Task 3: Панель и карта
`CommandPost.tsx` вместо «Войска» в режимах агентов: заголовок пункта (кто отдаёт; взят / через голову), выбор штаба
ступени (список или щелчок по знаку на карте), список получателей, форма директивы по таблице; рубежи, ось и линии —
щелчками по карте («Готово»); проект на карте (ось — стрелкой, рубежи и линии — линиями); «Отдать» ставит команду
`directive` в очередь хода. Уровень карты ↔ пункт: переключение одного переключает другое. Голос: `command.post`
(«штаб, пункт управления армии»), `command.directive.give`.
