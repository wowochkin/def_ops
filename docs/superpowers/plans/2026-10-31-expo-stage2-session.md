# Выставочный режим: сеанс и модель — план (этап 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Переломы обоих фронтов идут по-настоящему: три карточки из авторского банка (историческая среди них без пометки), выбор отдаётся ядру, прокрутка считает отрезок до следующего перелома, промедление — «армии продолжают прежние задачи», после третьего перелома — досчёт до конца операции; три шкалы (скорость, цена, замысел) по ходу и итог по осям со званием.

**Architecture:** Банк — данные `apps/editor/src/expo/bank-data/berlin-1945.cards.json` (переломы, карточки с распоряжениями армиям на объекты театра, источники или допущения, эталон потерь по истории). `expo/bank.ts` — типы, проверка формы, раздача и замена карточек. `expo/score.ts` — оси, шкалы, звание, прогноз, строки хода — чистые функции над событиями и потерями (`agentsEvents`, `lossSeries` из `@def-ops/sim`). `expo/session.ts` — сеанс модели поверх команд ядра (`game_start` / `game_turn` / `game_take` / `game_release`, режим «История как замысел»): историческая карточка — ничего не менять, своя — распоряжения армиям, промедление — фронт взят у истории без новых распоряжений до следующего перелома. Режиссёр выдаёт эффекты `deal`, `replace`, `decide`; хост ведёт сеанс модели и рассылает его вид (`model`) вместе с кадром. Сцены — простые (карта и анимация — этап 4).

**Tech Stack:** TypeScript/React, vitest; ядро — `target/release/agents-game` через `scripts/agents-bridge.mjs` (тест переломов пропускается без бинаря).

**Spec:** `docs/superpowers/specs/2026-10-30-expo-mode-design.md`, разделы 1.2–1.10, 2.5–2.7, 4.4.

## Global Constraints

- Ядро и полный режим не меняются: отпечатки `SEELOW_48_DIGEST`, `LEGACY_GAME_DIGEST` прежние.
- Тексты карточек — авторские пересказы фактов (4–5 строк), у каждой карточки — источник или пометка «допущение».
- Моменты переломов: 1-й Белорусский — 16.04 05:00, 20.04 05:00, 24.04 05:00; 1-й Украинский — 16.04 05:00, 18.04 05:00, 23.04 05:00.
- Проверки: `npx vitest run <файл>`; коммит после каждой задачи.
