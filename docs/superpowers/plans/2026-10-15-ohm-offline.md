# OpenHistoricalMap офлайн: карта на дату в редакторе и переигровке — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** скачивать исходные объекты OpenHistoricalMap (OHM) района (весь театр операции) через их Overpass участками 0,25° × 0,25°, собирать из них слои (дороги, железные дороги, вода, земли, здания, границы, пункты, значимые места) с датами начала и конца, нарезать векторные тайлы z0–16 в один MBTiles в папке данных службы картографии и показывать карту подложкой без интернета — в редакторе на дату шкалы времени или заданный год, в переигровке и игре на начало операции; переносить пакетом, обновлять повторной загрузкой.

**Architecture:** общее для OHM (разбор дат `ohmDate` и десятичный год `ohmYear`, сетка участков `ohmCells`, склейка колец `stitchRings`, адрес `OHM_OVERPASS`) переезжает из `packages/sim/src/overlay-network.ts` в новый `packages/core/src/ohm.ts` — его берут и служба картографии (у неё нет зависимости от `@def-ops/sim`), и `overlay-network.ts` (реэкспорт, без дублирования). В службе картографии: `src/ohm.ts` — участки Overpass (запрос, проверка ответа, повторы, кэш сырых участков в папке карты, шрифты и значки), `src/ohm-features.ts` — объекты OSM → признаки слоёв (`OhmCollector`: дубликаты по id, мультиполигоны и границы из путей всех участков), `src/vector.ts` — нарезка `@maplibre/geojson-vt` + `@maplibre/vt-pbf` по полосам уровней и блокам z10 в MBTiles (`node:sqlite`, как `archive.ts`) и чтение тайлов, `src/ohm-style.ts` — стиль MapLibre по мотивам OHM; маршруты и задание `ohm-download` — в `src/app.ts` через существующие `JobRunner`/`refreshMap`/пакеты. В редакторе: `BasemapSpec` получает `style` и `dated`, `MapEngine.setBasemapDate(iso)`; чистые функции векторной подложки — `apps/editor/src/engine/vector-basemap.ts`, адаптер — `engine/maplibre.ts`; форма «+ OpenHistoricalMap» и строки карты — `MapsPanel.tsx`; дата — `App.tsx` (шкала или поле года), `ReplayView.tsx` и `CommandView.tsx` (начало операции).

**Tech Stack:** TypeScript, Node 22 (`node:sqlite`, `node:zlib`), `@maplibre/geojson-vt` 6.1.1 и `@maplibre/vt-pbf` 4.3.2 (новые зависимости службы картографии; в тестах — `@mapbox/vector-tile` 3.0.0, `pbf` 5.1.2, `@maplibre/maplibre-gl-style-spec` 26.4.4), vitest, React, MapLibre GL; модель переигровки и Rust не меняются.

**Spec:** `docs/superpowers/specs/2026-10-15-ohm-offline-design.md`

## Global Constraints

- **Библиотеки нарезки** — форки MapLibre: `@maplibre/geojson-vt@6.1.1` (`GeoJSONVT`, типизирован, ESM; 6.1.2 в дереве моложе двух недель) и `@maplibre/vt-pbf@4.3.2` (`fromGeojsonVt`; на `pbf@5`, уже стоящем в дереве у `maplibre-gl`). Оригиналы `geojson-vt`/`vt-pbf` Mapbox не берутся: `vt-pbf@3.1.3` тянет `pbf@3` и `@mapbox/vector-tile@1` вторыми копиями. Версии — точные (`--save-exact`). Обе — чистый JS: `scripts/desktop-bundle.mjs` вшивает их в `cartography.mjs` (внешние там только `sharp` и `pg-native`) — проверяется в задаче 3.
- **Участки:** шаг 0,25°; от юго-западного угла рамки; по строкам с юга на север, в строке — с запада на восток (`i = r · cols + c`); последний столбец и строка обрезаются рамкой; `cols = ceil((e − w) / 0,25 − 1e-9)`, так же `rows` (без допуска `(52,65 − 52,4) / 0,25` даёт лишнюю строку); координаты — `+v.toFixed(6)`. Театр `[11.0, 50.9, 15.6, 54.45]` → 19 × 15 = 285 участков. Больше 1000 участков — 422.
- **Запрос Overpass участка** (ровно эта строка, рамка в порядке юг, запад, север, восток): `[out:json][timeout:180];(node(s,w,n,e)(if:count_tags()>0);way(s,w,n,e););out body geom;rel(s,w,n,e);out body;` — узлы только с тегами (неотмеченные узлы геометрии путей уже внутри `geom`: на пробном участке центра Берлина 138 узлов вместо 3055, ответ вдвое меньше), пути целиком с геометрией (в том числе без тегов — члены отношений), отношения — только члены-ссылки (огромные отношения границ не повторяются с геометрией в каждом участке; их кольца и линии собираются из путей всех участков). Тело — `data=<запрос>` (`application/x-www-form-urlencoded`), `User-Agent` — как у загрузки XYZ (`XYZ_USER_AGENT`, по умолчанию `USER_AGENT`; проверено: сервер принимает его, `curl/…` и `node`, отвергает `Python-urllib` — 403).
- **Ответ годен**, если HTTP 200, тело — JSON с массивом `elements` и без `remark`, содержащего `runtime error`, `timed out` или `out of memory` (Overpass при нехватке времени отвечает 200 с частью данных и `remark`). Иначе: 429, 5xx, обрыв, таймаут (300 с), не-JSON, `remark` — повтор; прочие 4xx — ошибка сразу. Повторов до 4 (`retries`), пауза `backoffMs · 2^(k−1)` (2, 4, 8, 16 с), `Retry-After` учитывается (не больше 60 с); между любыми двумя запросами к Overpass — не меньше `pauseMs` (1000 мс). Участок не скачан после всех повторов — задание `failed` с сообщением «участок N из M: …»; скачанные остаются.
- **Кэш участков:** `{TILES_DIR}/{орг}/{карта}/_ohm/plan.json` (`{ bbox, step, cells }`) и `_ohm/cells/{i}.json.gz` (запись `writeAtomic`): файл есть — участок скачан. Другая рамка в `plan.json` — кэш очищается. «Продолжить» берёт кэш, «обновить» (`refresh`) очищает `_ohm` в начале. После успешной нарезки `_ohm` удаляется.
- **Слои, классы и уровень появления (`minzoom` — только 0, 8, 10, 13):**
  | Слой | Объекты OHM | `class` | `minzoom` |
  |---|---|---|---|
  | `roads` (линии) | `highway` = motorway, trunk, primary (и `_link`) / secondary, tertiary (и `_link`) / unclassified, residential, living_street, road / service, track, path, footway, cycleway, bridleway, steps, pedestrian | значение `highway` | 0 / 8 / 10 / 13 |
  | `rail` (линии) | `railway` = rail / light_rail, narrow_gauge, subway, tram, funicular, monorail (abandoned, razed, dismantled, proposed, construction — нет) | значение `railway` | 0 / 10 |
  | `water` | линии `waterway` = river, canal / stream, ditch, drain; площади `natural=water`, `waterway=riverbank`, `landuse` = reservoir, basin, `water=*` | значение / `water` | 0 / 10; площади 0 |
  | `landuse` (площади) | `landuse` = forest, farmland, meadow, grass, residential, industrial, commercial, retail, cemetery, allotments, orchard, vineyard, military, railway, quarry, farmyard; `natural` = wood, heath, scrub, grassland, wetland; `leisure` = park, garden; `amenity=grave_yard` → `cemetery` | значение | 8 |
  | `buildings` (площади) | `building` ≠ no | значение `building` | 13 |
  | `boundaries` (линии) | члены отношений `type=boundary` + `boundary=administrative` (с тегами отношения), пути `boundary=administrative` | `admin_level` ≤ 4 → `country`, иначе `admin` | 0 / 8 |
  | `places` (точки) | `place` = city, town / village / suburb, hamlet, quarter, neighbourhood, isolated_dwelling, locality | значение `place` | 0 / 8 / 10 |
  | `pois` (точки с `name`) | `amenity=place_of_worship`, `railway` = station, halt (→ `station`), `historic` = castle, monument, memorial, fort, `amenity=townhall` | значение | 13 |
  Площадь — замкнутый путь (≥ 4 точек, первая = последней) с тегом площади (`building`, `landuse`, `natural` из таблицы и `water`, `leisure`, `amenity=grave_yard`, `waterway=riverbank`, `water`, `area=yes` без `highway`); остальное — линия; путь без подходящего класса — не объект (но хранится как член отношений). Мультиполигон (`type=multipolygon`): внешние кольца — `stitchRings` членов `outer` и с пустой ролью, дыры (`inner`) — к внешнему кольцу, содержащему их первую точку (`pointInRing`); по признаку на внешнее кольцо; незамкнувшееся кольцо (член вне театра) — пропуск без исключения. Член границы, входящий в несколько отношений с одинаковыми `admin_level`, `from`, `to`, — одна линия.
- **Свойства признака:** `layer`, `class`, `minzoom`, `id` (`n1`, `w10`, `r100/0` — номер внешнего кольца, `r102/w16` — член границы), необязательные `name`, `from`, `to` (десятичный год, 4 знака), `bridge: 1`, `tunnel: 1`, `admin_level` (число). Без даты — свойства нет (= «всегда»).
- **Даты:** `ohmYear(v, end = false)` = `год + (день года − 1) / (дней в году)` от `ohmDate(v, end)` (тот же разбор, что у исторического слоя: «1936», «1936-09», «1936-09-27», «~1930»; неполный конец — по 28-е число последнего месяца); не разобрать — `null`. Принимает и ISO с временем (`1945-04-16T05:00:00+03:00` — по дате). Показ на год `Y`: `(нет from или from ≤ Y) и (нет to или to ≥ Y)` — обе границы включительно.
- **Дата показа:** редактор — время шкалы (`time`), без него — `${год}-01-01`, год из поля «Год карты» (по умолчанию 1945, хранится в `localStorage` `def_ops.basemap.year`); переигровка — `result.start`, игра — `view.start`, по ходу не меняется; «Карты → Подложки» и «Карты → Театры» — поле года.
- **Нарезка:** `GeoJSONVT` с `extent 4096`, `buffer 64`, `tolerance 3`, `maxZoom 16`. Полосы уровней: z0–7 (признаки `minzoom 0`) и z8–9 (`minzoom ≤ 8`) — одним индексом на весь район; z10–12 (`minzoom ≤ 10`) и z13–16 (все) — по блокам-тайлам z10 района: в индекс блока — признаки, рамка которых задевает блок (с запасом 1/16 блока), тайлы — только внутри блока. Тайл без признаков не пишется. Признаки тайла делятся по `layer` в слои MVT (`fromGeojsonVt`, `version 2`), тайл сжимается gzip.
- **MBTiles 1.3:** таблицы `metadata(name, value)` и `tiles(zoom_level, tile_column, tile_row, tile_data)` с уникальным индексом, `tile_row` — по TMS (`2^z − 1 − y`); `metadata`: `name`, `format = pbf`, `minzoom = 0`, `maxzoom = 16`, `bounds` (`w,s,e,n`), `center`, `attribution = © участники OpenHistoricalMap, CC0`, `description`, `json` (`{"vector_layers":[{ id, fields, minzoom, maxzoom }…]}` по восьми слоям). Файл — `{карта}/ohm.mbtiles`; новая нарезка пишется в `ohm.mbtiles.tmp` и заменяет старый файл в конце (до этого показывается прежняя карта; читатель закрывается перед заменой и перед удалением карты).
- **Шрифты и значки** — общие для всех организаций, `{TILES_DIR}/.ohm-assets/` (точка в имени — как у `.uploads`): `fonts/{стек}/{диапазон}.pbf` для стеков `OpenHistorical`, `OpenHistorical Italic`, `OpenHistorical Bold` и диапазонов `0-255`, `256-511`, `1024-1279` (кириллица), `8192-8447` (тире, кавычки) — 12 файлов по 100–135 КБ с `https://www.openhistoricalmap.org/map-styles/fonts/{стек}/{диапазон}.pbf` (проверено `curl -A curl/8.5.0`: все 12 — 200; `60000-60255` — 404); `sprites/ohm.json`, `ohm.png`, `ohm@2x.json`, `ohm@2x.png` с `…/map-styles/historical/historical_spritesheet{,@2x}.{json,png}` (200; в нём есть `place_of_worship-18`, `railstation-18`, `capital-18`, `city-18`, `townhall-18`). Скачиваются в начале задания, если их нет.
- **Отдача:** тайл — `application/x-protobuf`, `Content-Encoding: gzip`, нет тайла — 204, адрес с `.png`/`.jpg`/`.webp` у векторной карты — 404; шрифт известного стека вне скачанных диапазонов — 200 с пустым телом (MapLibre не сыплет ошибками), неизвестный стек, диапазон не `\d+-\d+` с шагом 256, `..` — 404; значки — только четыре имени. Стиль: `glyphs`, `sprite`, `tiles` — пути от корня с префиксом шлюза (`publicPrefix`), источник `ohm` (`type: vector`, `maxzoom: 16` — глубже MapLibre растягивает до z19+); все `*-opacity` в стиле — числа (движок их умножает на прозрачность подложки; выражение `zoom` внутри `*` недопустимо); подпись «© участники OpenHistoricalMap, CC0». Граница карты (`coverage`) у векторной карты не применяется (PATCH `coverage` → 422).
- **Карта (`MapSource`):** `kind: 'vector'`, `format: 'pbf'`, `tileSize: 512`, `minzoom 0`, `maxzoom 16`, `bounds` = рамка, `attribution` — подпись выше, `stats` — `{ tiles, bytes }` из MBTiles (`count(*)`, размер файла), новое поле `ohm: { bbox, cells, features, layers: Record<слой, число>, fetchedAt }`; `description` — «OpenHistoricalMap: N объектов, участков M». `POST /cartography/maps` с `kind: 'vector'` или `format: 'pbf'` — 422 (векторная карта — только через `/maps/ohm` или пакет). Задание — `type: 'ohm-download'`, `total = участков + блоков z10 + 1`, `done` растёт по участкам, затем по блокам; `skipped` — участки из кэша; `message` — «шрифты и значки» → «участок N из M, объектов K» → «сборка объектов: K» → «нарезка: блок B из NB, тайлов T» → итог «Объектов K, тайлов T, X МБ».
- **Пакет векторной карты** (tar): `map.json` (с `kind: 'vector'`), `ohm.mbtiles`, `assets/fonts/{стек}/{диапазон}.pbf`, `assets/sprites/{имя}`; импорт — новая карта `kind: 'vector'`, MBTiles — потоком в папку карты (под общим пределом `MAX_PACKAGE_MB`), значки и шрифты пишутся, если их нет; `kind: 'vector'` без `ohm.mbtiles` — 422 и карта не остаётся. Импорт `.mbtiles` с `format=pbf` через «из файла» вне задачи.
- **Оценка до начала** (`ohmEstimate`): участков; минут — `ceil(участков · OHM_SEC_PER_CELL / 60)`; МБ — `round((e − w)(n − s) · OHM_MB_PER_SQDEG)`; начальные `OHM_SEC_PER_CELL = 6`, `OHM_MB_PER_SQDEG = 25` (театр — 285 участков, 29 мин, 408 МБ) заменяются замером прогона по театру (задача 6); тесты ссылаются на константы, а не на числа.
- **Настройки службы:** `OHM_OVERPASS_URL` (по умолчанию `OHM_OVERPASS`), `OHM_ASSETS_URL` (`https://www.openhistoricalmap.org/map-styles`), `OHM_PAUSE_MS` (1000). Настольное приложение (`STORAGE=file`, `DATA_DIR`, `TILES_DIR` из `apps/desktop/server/launch.mjs`) ничего нового не задаёт: карта — в `cartography.json`, MBTiles, кэш участков и шрифты — в `tiles/`.
- Данные OHM в расчёте не используются, правила модели не меняются — строки в `norms.json` нет. Язык интерфейса, описания, коммитов — русский; в описании нет дат и упоминаний ассистента и веток. По правилам репозитория: описание (часть I — разделы 3.2, 5, 6, 11; часть II — 17.2), снимки, `kb:seed`, `model:index`, `docs:system`, `docs:guide`; перед каждым коммитом `npm run typecheck` и `npm test`.

## Review Focus

1. Overpass отвечает HTTP 200, но с `remark: "runtime error: Query timed out…"` и частью `elements`, или HTML-страницей ошибки; другой участок — 400. Частичный ответ не должен лечь в кэш как скачанный участок: повтор, после всех повторов — задание `failed` с номером участка, в кэше — только предыдущие участки, «продолжить» запрашивает лишь недостающие; 400 — без повторов. Тест — задача 2.
2. Отношение, чьи пути пришли в разных участках, и член, которого нет ни в одном участке (за краем театра); тот же путь в двух соседних участках; одна граница-путь в нескольких отношениях. Кольцо мультиполигона склеивается из путей обоих участков, отношение с недостающим членом пропускается без исключения, дубликаты — по одному признаку. Тест — задача 2.
3. Признак длиннее или больше блока z10: дорога через весь район, лес шире блока, — и уровни ровно на границах полос (z7/z8, z9/z10, z12/z13). Признак есть в тайлах всех блоков, которые задевает (без разрывов на стыках блоков, без повторов в тайле), лес заливает тайл внутри себя целиком; здание — с z13, не на z12. Тест — задача 3.
4. Даты на краях: `to` ровно равно дате показа (виден), только `to` без `from`, `from > to` (плохие данные — не виден никогда), дата шкалы со временем и поясом, год без шкалы. Тест — задача 1 (`ohmYear`) и задача 5 (`dateFilter`, `basemapDate`).
5. Прерывания: отмена «обновить» на середине загрузки и перезапуск службы в режиме файлового хранилища (`persistent`) посреди загрузки. Прежняя карта остаётся видна байт в байт (тайлы, `ohm.fetchedAt`), задание помечено неудавшимся, «продолжить» начинает с первого не скачанного участка. Тест — задача 4.
