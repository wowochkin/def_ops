# Автономный комплект выставочного режима

**Цель:** перенести приложение, библиотеку и голос на поддерживаемый компьютер без Node, Python и инструментов разработки. LM Studio и выбранные LLM/embeddings устанавливаются отдельно.

**Спецификация:** `docs/expo-portable-release.md`.

**Архитектура:** платформенное приложение Tauri, независимый Node, переносимый Python и модели голоса; проверяемый SHA256-манифест библиотеки. Файловая библиотека импортируется до запуска сервисов, IndexedDB — до открытия интерфейса. Импорт добавляет отсутствующие записи и сохраняет пользовательские изменения. Секреты, журналы сеансов и назначения экранов не экспортируются.

**Стек:** Rust/Tauri, TypeScript/React/IndexedDB, Node, Python/MLX или Torch/CUDA.

**Ограничения:** не перезапускать текущий игровой сеанс, не менять модель боя, не выдавать проверку на Mac за проверку Windows. Windows 10 / RTX 4060 Ti сейчас недоступна. Существующие изменения рабочего дерева сохраняются.

## Внимание при проверке

Отсутствие ссылок на Homebrew, исходный профиль и репозиторий; отсутствие внешних загрузок при старте; целостность всех ресурсов; перенос пользовательской базы и голосов; лицензии; безопасное обновление существующего профиля; самостоятельная работа трёх дисплеев требует проверки на физическом стенде.

## Продолжение: перенос сборки на Windows

Пользователь переносит набор и запускает сборку самостоятельно; прямого доступа к ПК нет.

- Проверены SHA256 всех 110 wheels; добавлены Node x64, rustup, VS bootstrapper и полный WebView2.
- Стартовый сценарий проверяет комплект, подготавливает инструменты, сохраняет отдельную попытку и журнал.
- Исправлена передача Python-кода в PowerShell 5.1: код передаётся файлом, не аргументом -c.
- Исправлена ошибка debug Tauri: автономные ресурсы не копируются поверх read-only target/debug. Ошибка воспроизведена, после исправления две сборки cargo check успешны.
- Ruling: приёмочная сборка явно допускает только два воспроизведённых score assertions, сохраняет их в отчёте. Физика и ожидания тестов не менялись; риск — оценки промедления пока не соответствуют заявленному контракту. Строгий режим остаётся доступен без DiagnosticCandidate.
- Проверка настоящего ядра на Windows обязательна: свежее agents-game.exe собирается до тестов.
- Полный прогон: 2631 прошёл, 2 известных падения, 34 пропуска; последующие 9 тестов классификатора прошли. Проверка TypeScript прошла.
- Свежий обзор выявил три ошибки передачи/классификации; для классификатора воспроизведены три падения новых тестов, затем все 9 прошли. UTF-8 манифест читается явно.
- Windows/CUDA, конечный EXE и физические дисплеи остаются этапом приёмки на ПК пользователя.
