# Голос через динамики — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** голосом можно пользоваться через динамики (перебивание словом, подавление эха), команды понимаются при
огрехах распознавания, пробу голоса можно прервать, голос можно выключить.

**Architecture:** перебивание словом и подавление эха — в `services/voice` (сессия, слушатель, распознавание
кусков во время речи штаба); выбор режима — калибровкой; кнопка вкл/выкл, остановка пробы и подсказки — в
`apps/editor/src/voice`; нестрогий разбор команд — в `dispatch.ts`.

**Tech Stack:** Python (FastAPI, numpy, GigaAM, `livekit` — AudioProcessingModule), TypeScript/React, vitest, pytest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-17-voice-speakers-design.md` (дополнение к
`docs/superpowers/specs/2026-10-17-voice-control-design.md`).

## Global Constraints

- Русский язык интерфейса, текстов, комментариев, коммитов; коммиты с двумя строками атрибуции сессии.
- Пользователи — люди старшего возраста и эксперты: простые слова, без технических терминов, без зависаний.
- Протокол: `say-done` = весь звук отправлен; `played` — после доигрыша; id 0 — звук калибровки; id пробы ≥ 1.
- Стоп-слова: «стоп», «подождите», «подожди», «хватит», «отставить», «тихо», обращение «штаб…» в начале.
- Перебивание словом: кусок речи от 0,5 с; цель — остановка за 0,6–0,9 с после начала стоп-слова; кусок,
  совпадающий по словам с текущей фразой штаба, не останавливает.
- Совета про наушники нет; при громком эхе: «Динамики слышно громко — чтобы перебить штаб, скажите «Стоп».»
- Выключение голоса: `localStorage['def_ops.voice.enabled']`; команда «Штаб, отбой» / «Штаб, выключи голос»;
  ответ «Голос выключен. Включить — кнопкой на панели.»
- Перед коммитом: `npm run typecheck`, `npm test`, `VOICE_PYTHON=… npm run test:voice`, `node scripts/voice-e2e.mjs`
  (и `--no-stub`), если задеты окно или сервис.

## Review Focus

- Перебивание словом не срабатывает на эхо фразы штаба, в которой есть слово «стоп»/«хватит» (Task 3, тест).
- Нестрогий разбор не открывает раздел по обычному слову («картинку», «знакомый», «штат» в середине фразы) (Task 2, тесты).
- Выключенный голос действительно освобождает микрофон и не переподключает его сам (Task 1, e2e).
- Подавление эха не портит речь человека, когда штаб молчит (Task 4/5, проверка на синтетике).
- Режим, выбранный калибровкой, переживает перезапуск и виден в «Тонкой настройке» (Task 3).

### Task 1: Проба голоса прерывается; кнопка «Выключить голос»

**Files:** `apps/editor/src/voice/Voices.tsx`, `Calibration.tsx`, `VoicePanel.tsx`, `client.ts`, `panel-state.ts`,
`styles.css`; тесты `apps/editor/tests/voice-panel.test.ts`; `scripts/voice-e2e.mjs`.

**Interfaces:**
- Produces: `VoiceClient.setEnabled(on: boolean)` — выкл: остановить воспроизведение, `stop()` всех фраз, закрыть
  микрофон (дорожки `stop()`), не переподключать микрофон, связь с сервисом можно держать; вкл: снова микрофон.
  Событие окна `voice:power` (`detail: boolean`) — его шлёт разборщик (Task 2) на «отбой»; панель слушает.
  Состояние панели «Голос выключен» (простые слова), значок — перечёркнутый микрофон.

- [ ] Тесты: e2e — «Прослушать» голоса A, затем голоса B: звучит только B (у A пришёл `say-done stopped` / звук
  прерван); закрыть окно «Голоса» во время пробы — звук прекращён; начать запись — проба остановлена; закрыть
  окно калибровки во время звука штаба — звук прекращён. Кнопка «Выключить голос» → дорожки микрофона
  остановлены (`track.readyState === 'ended'`), состояние «Голос выключен»; перезагрузка страницы — остаётся
  выключенным; «Включить голос» → «Жду обращения». Чистые тесты — состояние панели при выключенном голосе.
- [ ] Реализация; прогон проверок из Global Constraints; коммит «Голос: проба голоса прерывается, голос можно выключить».

### Task 2: Команды при огрехах распознавания и «отбой»

**Files:** `apps/editor/src/voice/dispatch.ts`, `apps/editor/tests/voice-dispatch.test.ts`, `VoicePanel.tsx` (только
показ поправки в ленте, если нужно).

**Interfaces:**
- Produces: `normalizeCommand(text: string) -> { text: string; fixes: string[] }` — нестрогая поправка обращения и
  названий разделов (похожесть слов, склейка соседних слов); `Dispatcher.utterance` возвращает поправки, лента
  показывает «Услышано: «…» — понял: «…»». Голое название раздела после обращения — `shell.open`. «Отбой» /
  «выключи голос» — событие `voice:power` (`false`) и ответ из Global Constraints.

- [ ] Тесты: «Штаб, переигровка» → replay; «Штаб, карты» → maps; «штап переигровку», «шаб, переигровка»,
  «штаб пере игровку», «штаб переигровк», «штаб, переиграть» → replay с поправкой в ответе; «Штаб, картинку»,
  «Штаб, знакомый», «передайте в штат армии» — не открывают ничего; «Штаб, отбой» и «Штаб, выключи голос» →
  `voice:power false`, ответ про кнопку.
- [ ] Реализация (простая похожесть: расстояние Левенштейна по словам с порогом от длины, плюс склейка двух
  соседних слов; без новых зависимостей); проверки; коммит «Голос: команды при огрехах распознавания, «отбой»».

### Task 3: Перебивание словом

**Files:** `services/voice/audio.py` (калибровка: режим вместо совета), `services/voice/server.py` (сессия: в режиме
«словом» VAD-кусок во время речи штаба → распознавание → стоп-слово/эхо → `barge`), `services/voice/fake.py`,
`services/voice/tests/*`; окно: `Calibration.tsx` (текст режима), `VoicePanel.tsx` (подсказка «Перебить: скажите
«Стоп»», переключатель режима в «Тонкой настройке»), `panel-state.ts` (настройка `barge_mode: 'voice'|'word'`),
`protocol.ts` (настройка в `settings`/`hello`).

**Interfaces:**
- Produces: `calibrate()` возвращает в cfg `barge_mode`; `is_stop_phrase(text: str, chief_text: str) -> bool`
  (стоп-слово/обращение в начале и не эхо фразы штаба по похожести слов); сессия в режиме «словом» не перебивает
  по громкости, распознаёт кусок (≥ 0,5 с, кусками по мере речи, без ожидания конца реплики) в torch-нити.

- [ ] Тесты (pytest, `--fake`): громкое эхо → `barge_mode == 'word'`, совета про наушники нет, текст про «Стоп»;
  в режиме «словом» реплика «стоп» во время фразы штаба → `barge`; эхо фразы штаба, содержащей «хватит», —
  без `barge`; посторонняя речь без стоп-слова — без `barge`; в режиме «голосом» — как раньше. Окно: e2e —
  подсказка «Перебить: скажите «Стоп»» видна, пока штаб говорит в режиме «словом»; режим в «Тонкой настройке»
  переключается и запоминается.
- [ ] Реализация; проверки; коммит «Голос: перебивание словом через динамики».
