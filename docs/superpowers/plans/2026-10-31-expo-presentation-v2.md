# План: подача выставки, вторая редакция

Спецификация — `docs/superpowers/specs/2026-10-31-expo-presentation-v2-design.md`. Коммит и push после каждого пункта.

1. **Замер.** `scripts/expo-perf.mjs`: заставка и прокрутка, 1920×1080 — кадры/с, длинные задачи (> 50 мс),
   коммиты React на кадр. Цифры до/после — ниже.
2. **Карта полного режима.** `MapView` с офлайн-подложкой (локальная карта службы картографии, иначе «Бумага»),
   документ — из хода ядра сеанса теми же функциями, что переигровка (`agentsToRun` → `runToDocument`).
   Один экземпляр на окно; поверх — стрелки карточки, движение армий по часам хода, пути по суточным точкам,
   пролёт камеры. Своя SVG-карта и `expo:map` — убрать.
3. **Карточка-приказ.** Портрет/эмблема, мини-карта стрелок, суть, факт с источником, риск; поля `fact`/`risk`
   в банке и проверка формы; штамп «ПРИКАЗ» и телетайп при выборе.
4. **Кинохроника.** Зерно, сепия, виньетка, шторка между сценами, табло даты, вспышки и дым — CSS/canvas без React.
5. **Картинки.** Портреты и кадры общественного достояния (Wikimedia Commons, PD), сгенерированные фоны; манифест и тест.
6. **Итог — газетная полоса.** «Совпало с историческим решением: N из 3», рекорд дня, приглашение за другой фронт.
7. **Заставка.** Призыв, архивные кадры, переигровка на карте полного режима; без сравнений с маршалами.
8. **Экраны на одном мониторе.** «Все вместе · 1 · 2 · 3», ←/→, вкладка «Экраны».
9. **Проверка.** Обзор снимков 1024×660 и 1920×1080, замер; описание 2.1, PDF/DOCX.

## Замер

| Сцена | Кадры/с | Длинные задачи | Самая длинная | Коммиты React на кадр |
|---|---|---|---|---|
| до: заставка | 60,1 | 0 | — | 0,27 |
| до: ввод в обстановку | 53,7 | 0 (кадр до 33 мс) | — | 0,89 |
| до: прокрутка | 55,3 | 1 (кадр до 83 мс) | 70 мс | 0,98 |

Условия: `node scripts/expo-perf.mjs`, Chromium без окна, 1920×1080, замедление процессора ×4 (машина стенда слабее
машины разработки; WebKit настольного приложения медленнее Chromium). Главная причина: камера, движение армий
и переигровка ведутся состоянием React — сцена перерисовывается почти на каждом кадре (≈1 коммит на кадр),
подписи карты пересчитываются на каждом кадре.

После (карта полного режима, кинохроника; замер ждёт готовности карты и пару секунд на выборе фронта):

| Сцена | Кадры/с ×4 | Длинные задачи ×4 | Кадры/с ×1 | Длинные задачи ×1 | Коммиты React на кадр |
|---|---|---|---|---|---|
| заставка | 59,5 | 0 | 59,9 | 0 | 0,23 |
| ввод в обстановку (пролёт камеры) | 37,7 | 1 (84 мс) | 53,5 | 0 | 0,8 |
| прокрутка | 56,7 | 0 | 59,9 | 0 | 0,35 |

Что сделано для этого: время карты бежит внутри `StageMap` (10 раз/с на заставке, 20 — на прокрутке), сцена
не перерисовывается; карта не размонтируется между сценами; документ — в воркере, только слои уровня фронта;
знаки «как на местности» — смена зума не перерисовывает все знаки; скачок времени к 16 апреля — на скрытой карте
выбора фронта; сепия — неподвижный тонирующий слой вместо CSS-фильтра карты; шторка — `transform`, не `clip-path`.
Остаток: при пролёте камеры `MapView` полного режима перерисовывается на каждое событие вида (≈0,8 коммита
на кадр), а Chromium без окна рисует WebGL программно — на настольном приложении с видеокартой пролёт легче;
это не проверено на стенде.
