# Погода и автономная картография — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Работать самостоятельно; согласование пользователь передал исполнителю.

**Goal:** Два работающих автономных модуля современного пространства.
**Architecture:** Чистый погодный движок в core, файловые наборы и API в cartography; отдельный каталог современных MBTiles и конвертер исходных данных в процессе Python. Интерфейс React/MapLibre без внешних ресурсов во время просмотра.
**Tech Stack:** TypeScript, Node SQLite, React, MapLibre, Python rasterio/osmium.
**Spec:** docs/superpowers/specs/2026-11-18-weather-cartography-design.md

## Global Constraints
- Историческую модель и её данные не менять.
- Поддержать автономное чтение, UTC, явные пропуски и происхождение данных.
- Не стирать существующие незакоммиченные доработки; коммит и публикация не запрошены.
- Самостоятельное исполнение без субагентов согласно предпочтению пользователя.

## Review Focus
- Повреждённый пакет не заменяет готовые данные.
- Погода не зависит от частоты кадров и направления перехода по времени.
- Ветер через север интерполируется по короткой дуге.
- Кириллица и нестандартные пути Windows работают без shell-команд.
- Недоступный интернет или runtime дают понятное состояние, а не вечное ожидание.

## Журнал
- Пользователь разрешил весь объём и автономное выполнение, включая конвертацию.
- Работа в текущей feature-ветке: старые изменения не переносим и не коммитим.

- Погодное ядро и импорты проверены тестами; добавлены ручные ключевые состояния.
- Геоданные: настоящие MBTiles/MVT, OSM и синтетические GeoTIFF прошли преобразование.
- Реальные запросы: ERA5 — 24 почасовых строки; OpenFreeMap — район Берлина, 16 слоёв, z8–14.
- Внешняя сеть заблокирована в браузерной проверке локальной карты; кириллица загружается локально.
- Исправлены повтор после отмены, отсутствие расширения у временного OSM-файла и лишняя перезагрузка карты при опросе прогресса.
- Полный прогон: 2784 пройдено, 34 пропущено; 2 ошибки исторической переигровки воспроизведены на исходном HEAD. Это не полностью зелёный набор.
- macOS .app собран; Windows wheels и автономный установщик подготовлены, реальная Windows не проверена.
- Решение: окружение GIS отдельно от TTS; поддерживается Python 3.12, отдельные платформенные бинарные дополнения.
- Коммит, пуш и замена установленного приложения не выполняются.

- На общем экране проверены включение погодного слоя, сценарий на 30 суток, копирование адреса и влияние высоты 123 м на температуру (16 → 15,2 °C).
- Автоматическая подготовка регионального PBF проверена до появления готового MBTiles в каталоге. Повторный запрос ERA5 из собранного приложения завершился ошибкой соединения с поставщиком.
