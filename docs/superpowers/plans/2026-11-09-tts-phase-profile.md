# Раздельный замер Qwen TTS

Пользователь запросил измерить долю генератора аудиокодов и звукового кодека на Windows RTX 4060 Ti.
Удалённого доступа к этой машине нет: поставляется отдельный автономный запускатель для переноса.

1. Снять время на границах `create_voice_clone_prompt`, `model.generate`, `speech_tokenizer.decode`
   закреплённой Qwen 0.1.1. Синхронизировать CUDA только на границах, отделить прогрев и steady-state.
2. Использовать существующий runtime, локальные веса/образец, активный профиль и параметры оператора;
   никаких установок, замены приложения и автоматического изменения квантования.
3. Проверить разбиение времени, восстановление методов, освобождение ссылок, целостность исходников,
   текущие параметры и реальные точки вызова закреплённого wrapper без заявления о скорости CUDA на Mac.
4. Обновить руководство и описание, пересобрать PDF/Word. Упаковать минимальный ZIP без кэшей,
   проверить состав/CRC/SHA256, скопировать на подключённый USB и сверить копию.

Нативные числа появятся после запуска `MEASURE.cmd` на Windows. Выход: report.txt/report.json,
журнал и WAV для одной фразы/пакета. Подготовка образца/прогрев не выдаются за постоянную стоимость
каждой фразы; речь, полученная при измерении, не подменяет рабочие записи.
