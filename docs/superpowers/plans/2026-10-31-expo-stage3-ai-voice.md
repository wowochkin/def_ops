# Выставочный режим, этап 3 «ИИ и голос» — план

Спецификация: `docs/superpowers/specs/2026-10-30-expo-mode-design.md` (раздел 3, «Порядок работ» п. 3, раздел 4).

## Global Constraints

- Всё деградирует без ИИ и голоса: сеанс не рвётся, ответ ИИ не готов в срок — звучит заготовка.
- Режиссёр остаётся чистой машиной; ИИ, голос и распознавание — исполнители эффектов в главном окне.
- Источник каждого текста виден на экране (раздел 3 п. 6).
- Тексты книг в репозиторий не попадают; отпечатки ядра не меняются.

### Task 1: Очередь голоса

`expo/voice-queue.ts`: фразы с приоритетами action > timer > event > ambient; новая важная фраза прерывает фоновую,
голос не говорит поверх себя; пусто — фоновая фраза из заготовок. Исполнитель речи — голосовой сервис (через
`VoiceClient`), иначе синтез окна, иначе молча (текст на экране). Тест: `tests/expo-voice-queue.test.ts`.

### Task 2: Заготовки фраз и подстановки «Без ИИ»

`bank-data/berlin-1945.lines.json`: фразы по ключам эффектов (timer-warn, delay, offer-decide, voice-soon, newSession,
приветствие, ввод), комментарии выбора с подстановками из хода, готовые ответы на вопросы, фоновые фразы.
`expo/lines.ts` — выбор и подстановка. Тест: `tests/expo-lines.test.ts`.

### Task 3: ИИ сеанса

`expo/ai.ts`: карточка по запросу (заранее при раздаче, проверка формы — та же, что у банка, запасной — банк),
ответ на вопрос и комментарий выбора со сроком (не успел — заготовка), источник у каждого текста.
`ExpoSession.replace` принимает готовую карточку. Тест: `tests/expo-ai.test.ts`.

### Task 4: Режиссёр, хост, виды

События `ask` (вопрос) и `speak` → эффекты `ask`, `listen`; хост ведёт кадр ИИ (речь, ответ, мысль) и рассылает его.
Кнопка «Спросить ИИ» с готовыми вопросами, «Говорить» — распознавание и разбор команд сеанса. Тест: режиссёр.

### Task 5: Команда подготовки

`npm run expo:prepare` — проверка банка и фраз (форма, длина, стоп-слова); `--generate` — кандидаты карточек от
языковой модели с автопроверкой формы и записью в банк; `--voice` — заготовка звука фраз голосовым сервисом.
