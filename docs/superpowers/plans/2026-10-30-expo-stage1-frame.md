# Выставочный режим, этап 1 «Каркас» — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выставочный режим запускается внутри приложения, открывает окна по раскладке 3/2/1 на нужных экранах, ведёт сеанс по фазам с таймером и бездействием (сцены — заглушки), принимает ввод по профилю, закрыт от полного интерфейса, управляется меню оператора и сам восстанавливается.

**Architecture:** Режиссёр сеанса — чистая машина состояний (`apps/editor/src/expo/director.ts`), живёт в главном окне; остальные окна — виды своей роли, получают состояние и шлют ввод по шине (события Tauri между окнами; в браузере разработки — `BroadcastChannel`). Окна на экранах открывает и стережёт настольное приложение (`apps/desktop/src-tauri/src/expo.rs`); настройки — файл `expo.json` в папке данных приложения.

**Tech Stack:** React/TypeScript (редактор), vitest (+ happy-dom, @testing-library/react уже в devDependencies), Tauri 2 (Rust), Playwright для живых снимков.

**Spec:** `docs/superpowers/specs/2026-10-30-expo-mode-design.md` (разделы 1, 2.11–2.13, 5, 6; этап 1 «Каркас» из «Порядка работ»).

## Global Constraints

- Язык интерфейса, описания, коммитов — русский; правила `CLAUDE.md` (описание `docs/system.md` и снимки 1440×900 JPEG с подписями о видимом, `npm run docs:system`, `model:index` при правке `packages/sim/src` или `crates/agents-core/src`; в описании нет дат, упоминаний ассистента и названий веток).
- Ветка `claude/expo`; в main — только после последнего этапа выставочного режима.
- Полный режим не меняется: прежние отпечатки `SEELOW_48_DIGEST`, `LEGACY_GAME_DIGEST`; полный интерфейс открывается как раньше, если выставочный режим не включён.
- В выставочном режиме — никаких сетевых обращений за пределы `127.0.0.1`/`localhost` (спецификация 5.6).
- macOS и Windows — одинаковое поведение; ничего платформенного без ветки на обе системы.
- Ничто на экранах посетителя не ведёт в полный интерфейс: нет меню, горячих клавиш (кроме сочетания оператора), контекстного меню, выделения текста, перетаскивания, масштабирования страницы, перехода по истории; выход — только из меню оператора (спецификация 2.13).
- Значения по умолчанию (спецификация): таймер включён, 30 с, предупреждение за 10 с; без таймера — предложение решить за посетителя через 30 с, решение ИИ ещё через 30 с; бездействие до заставки — 90 с; возврат после итога — 20 с; фронты — оба; до 2 замен карточки на перелом.
- Проверки экономно: `npx vitest run <файл>`, `npm run typecheck 2>&1 | tail -3`, `npm test 2>&1 | grep -E "Test Files|Tests |FAIL"` один раз перед коммитом задачи; `cargo check -p defops-desktop 2>&1 | tail -3` для Rust приложения.

## Review Focus

1. **Окно закрыли** (Cmd+W/Cmd+Q, Alt+F4, системный жест) — приложение не выходит, окно вида открывается снова, сеанс идёт. Тест — задача 4 `closing expo window reopens it`, задача 5 `lockdown blocks quit keys`.
2. **Экран отключили посреди сеанса** — раскладка перестраивается на меньшую, режиссёр не сбрасывает фазу, роли переезжают. Тест — задача 3 `layout shrinks keeps phase`, задача 4 `monitor loss relayouts`.
3. **Файл настроек испорчен, отсутствует или старой версии** — значения по умолчанию, неизвестные поля отброшены, программа не падает, испорченный файл сохранён рядом как `expo.json.bad`. Тест — задача 1 `corrupt settings fall back`.
4. **Два касания разом или двойной выбор** (касание плюс мышь, дребезг) — второй выбор той же фазы игнорируется, фаза не перескакивает. Тест — задача 2 `double choose ignored`.
5. **Меню оператора открыто посреди сеанса** — таймер и бездействие на паузе, по закрытии продолжаются с того же места; бездействие не выкидывает в заставку под меню. Тест — задача 2 `operator pause freezes timers`.

### Task 2: Режиссёр сеанса — фазы, таймер, промедление, бездействие

**Files:**
- Create: `apps/editor/src/expo/director.ts`, `apps/editor/tests/expo-director.test.ts`

**Interfaces:**
- Consumes: `ExpoSettings`, `FrontId` (задача 1).
- Produces:
  - `type Phase = { kind: 'startup' } | { kind: 'attract' } | { kind: 'welcome' } | { kind: 'briefing' } | { kind: 'turn'; n: 1 | 2 | 3; step: 'explain' | 'choose' | 'scroll'; deadline: number | null; warned: boolean; offered: boolean; choice: number | 'delay' | null; replacements: number } | { kind: 'result' }`.
  - `interface DirectorState { phase: Phase; front: FrontId | null; phaseStart: number; lastInput: number; paused: boolean; pausedAt: number | null; session: number; stats: { sessions: number; finished: number } }` — время — миллисекунды по часам режиссёра.
  - `type DirectorEvent = { t: 'tick'; now: number } | { t: 'ready' } | { t: 'touch' } | { t: 'pickFront'; front: FrontId } | { t: 'next' } | { t: 'choose'; card: number } | { t: 'replace'; card: number } | { t: 'restart' } | { t: 'pause' } | { t: 'resume' } | { t: 'jump'; phase: Phase['kind']; n?: 1 | 2 | 3 }`.
  - `type Effect = { e: 'say'; key: string; priority: 'action' | 'timer' | 'event' | 'ambient' } | { e: 'aiPick'; n: 1 | 2 | 3 } | { e: 'newSession' } | { e: 'stat'; kind: 'started' | 'finished' }`.
  - `const DURATIONS = { welcome: 20_000, briefing: 35_000, explain: 10_000, scroll: 20_000 }` (миллисекунды; заглушки этапа 1 переходят по ним сами).
  - `function initialState(now: number): DirectorState` — фаза `startup`.
  - `function step(s: DirectorState, ev: DirectorEvent, cfg: ExpoSettings): { state: DirectorState; effects: Effect[] }` — чистая.
- Правила (из спецификации):
  - `startup` → `attract` по `ready`; `attract` → `welcome` по `touch`; `welcome` → `briefing` по `pickFront` (фронт из `cfg.fronts`; один фронт — `welcome` выбирает его сам по `touch`); `briefing` → `turn 1 explain` по времени или `next`; `explain` → `choose` по времени; `choose` → `scroll` по `choose`; `scroll` → следующий перелом или `result` после третьего; `result` → `attract` через `cfg.resultSeconds`, или `welcome` по `touch` («Ещё раз»).
  - Таймер включён: `deadline = вход в choose + seconds·1000`; за 10 с — `say timer-warn` (priority `timer`), `warned`; истекло — `choice: 'delay'`, `say delay`, переход в `scroll`.
  - Таймер выключен: через 30 с в `choose` — `say offer-decide`, `offered`; ещё через 30 с — эффект `aiPick`, `choice` выставит последующий `choose` от оболочки.
  - Бездействие: любая фаза, кроме `startup` и `attract`, без ввода (`touch`, `pickFront`, `next`, `choose`, `replace`) дольше `cfg.idleSeconds` — `attract` и `newSession`.
  - `restart` в любой фазе после `attract` — `welcome`, `newSession`, новый `session`.
  - `replace` — не больше `cfg.maxReplacements` на перелом; лишнее — игнор.
  - `pause` замораживает отсчёты (`deadline`, бездействие, длительности); `resume` сдвигает их на длительность паузы.
  - `jump` — переход к фазе для показа (перелом — с `n`), начало фазы — сейчас.
  - Статистика: `stat started` при входе в `briefing`, `stat finished` при входе в `result`.

- [ ] **Step 1: Падающие тесты** (`expo-director.test.ts`; помощник `run(events)` прогоняет события от `initialState(0)` с `EXPO_DEFAULTS`):
  - `full session path` — ready, touch, pickFront('su_1bf'), tick до конца briefing, explain, choose(0), tick до конца scroll — три раза → фаза `result`, эффекты `stat started`, `stat finished`; затем tick на 20 с → `attract`.
  - `single front skips choice` — `cfg.fronts = ['su_1uf']`: touch в `welcome` → `briefing`, `front === 'su_1uf'`.
  - `timer warns and delays` — в `choose`: tick на 20 с → `say timer-warn`, на 30 с → `choice === 'delay'`, `say delay`, фаза `scroll`.
  - `timer off offers then ai picks` — `timer.on = false`: 30 с → `say offer-decide`; 60 с → эффект `aiPick` с `n` текущего перелома; фаза остаётся `choose`.
  - `idle returns to attract` — в перелом 2 без ввода 90 с → `attract`, эффект `newSession`.
  - `double choose ignored` — два `choose` подряд в одной фазе: второй не меняет `choice`, фаза `scroll` не перескакивает дальше.
  - `operator pause freezes timers` — pause в `choose` на 5 с до дедлайна, tick на +120 с, resume, tick на +4 с → ещё `choose`; tick ещё +2 с → `delay`; бездействие не сработало.
  - `replace limited` — три `replace` при `maxReplacements = 2` → `replacements === 2`.
  - `restart from any phase` — restart в `turn 2 scroll` → `welcome`, `session` увеличен, `newSession`.
  - `jump for demo` — `jump('turn', 3)` из `attract` → `turn 3 explain`.
