# Берлин-1945: объекты (мосты и переправы, полосы обороны, крепости, узлы снабжения)

Результат поиска по открытым источникам для агентной модели (раздел 2 плана: мост — цел /
повреждён / взорван / наведена переправа; населённый пункт — обороняется, подготовлен; склад).
Данные — в `berlin-1945-objects.json`; то, что уже внесено в другие файлы
(`berlin-1945-seelow-divisions.json` — четыре полосы Одерского рубежа; `berlin-1945-conquest.json`
и `berlin-1945-halbe.json` — мосты по Ле Тиссье; `berlin-city-1945.recipe.json` — секторы и
обводы Берлина), не дублируется, а только привязывается ссылками.
