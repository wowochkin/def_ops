# Испытание голоса: синтез с клонированием, распознавание, языковая модель

Одноразовый набор для выбора моделей голосового разговора на Mac (Apple Silicon): всё локально, модели
скачиваются с Hugging Face при первом запуске. В систему не встраивается; по итогам выбираются модели для
голосового режима.

Что сравнивается:

| Звено | Кандидаты | Что меряем |
|---|---|---|
| Синтез с клонированием | Qwen3-TTS 1.7B и 0.6B, Fish S2 Pro, VoxCPM2, OmniVoice, Chatterbox Multilingual v3 (все — MLX через mlx-audio), Higgs Audio v3 (по желанию), Voicebox (его API: Qwen3-TTS, Chatterbox, OmniVoice) | слепое прослушивание (естественность, похожесть, ошибки чтения), разборчивость по Whisper, время до первого звука, скорость, память |
| Распознавание | Whisper large-v3-turbo, Parakeet v3 (MLX), GigaAM v3 (Сбер), T-one (Т-Банк) | доля ошибок по словам на ваших записях, время |
| Языковая модель | модель в LM Studio (по умолчанию — первая с qwen3.6 в имени) | время до первой фразы ответа, ток/с |

Образец голоса — куски архивной записи пресс-конференции о Берлинской операции (mp3, 1:56). В записи сильный
ровный гул ниже 80 Гц (громче речи) — prepare_ref.sh срезает его фильтром; полоса записи — до ~5 кГц,
поэтому и клон будет звучать «архивно». Варианты образца — в refs.json: 14 с (основной), 10 с, 22 с, без
фильтра и с шумоподавлением DeepFilterNet.

## Порядок

```bash
cd scripts/voice-bench
./setup.sh                                  # окружения (uv, ffmpeg); с T-one — ./setup.sh --tone
./prepare_ref.sh ~/Downloads/<запись>.mp3   # образцы в ref/

# 1. синтез: все движки (около 15–30 мин, первый раз дольше — скачивание моделей, ~40 ГБ)
.venv-tts/bin/python tts_bench.py
#    второй проход — другие образцы для двух лучших движков, например:
.venv-tts/bin/python tts_bench.py --engines qwen3-1.7b,fish-s2-pro --ref zhukov-22s
.venv-tts/bin/python make_listen.py         # out/listen-zhukov-14s.html — слушать и оценивать
.venv-tts/bin/python score.py --asr         # out/report-zhukov-14s.md (оценки — out/ratings-zhukov-14s.json)

# 2. распознавание: прочитать 12 фраз в микрофон, затем прогон
.venv-stt/bin/python record.py
.venv-stt/bin/python stt_bench.py           # out/stt.md

# 3. языковые модели: LM Studio запущен (сервер, JIT-загрузка моделей включена)
python3 llm_compare.py run --models <id1>,<id2>   # id — из `curl -s localhost:1234/v1/models`
.venv-tts/bin/python llm_voice.py                 # озвучить ответы голосом (Qwen3-TTS 1.7B, образец Жукова)
python3 llm_compare.py page                       # out/llm-read.html — слушать/читать вслепую и оценивать
python3 llm_compare.py score                      # out/llm.md
```

**Voicebox.** Установите приложение (voicebox.sh), создайте профиль голоса «Жуков» из `ref/zhukov-14s.wav`
с расшифровкой из `refs.json`, скачайте в нём модели Qwen3-TTS 1.7B, Chatterbox и OmniVoice. Пока приложение
открыто, `tts_bench.py` берёт его движки (`voicebox-*`) по API `http://127.0.0.1:17493`. Без Voicebox эти
строки просто дадут ошибку загрузки — остальные движки пройдут.

## Что прислать

`out/report-zhukov-14s.md`, `out/ratings-zhukov-14s.json`, `out/stt.md`, вывод `llm_bench.py` и 2–3 лучших
и худших файла из `out/tts/`. Записи и образцы остаются у вас (в git не попадают: см. .gitignore).

## Если движок не запустился

Ошибка одного движка не останавливает остальные: строка с ошибкой попадёт в отчёт. Нехватка модуля Python —
`uv pip install --python .venv-tts/bin/python <модуль>` и повтор с `--engines <id>`. Названия весов
в mlx-community — в engines.json (берётся первый доступный вариант).

Лицензии: Fish S2 Pro и Higgs v3 — только некоммерческое использование; Qwen3-TTS, VoxCPM2 — Apache 2.0;
Chatterbox — MIT. Синтез голоса реального человека — только для локальной работы с системой, без
распространения записей как подлинных.

## Живой разговор (talk_server.py)

Говорите свободно: модель сама слышит конец реплики, отвечает голосом Жукова и её можно перебить — просто
заговорите. Цепочка: речь (Silero VAD) → конец реплики (Smart Turn) → распознавание (GigaAM v3) → поправка
названий театра → Qwen3.6 в LM Studio (без размышления, поток) → фразы → Qwen3-TTS 1.7B (поток) → звук.

```bash
./setup.sh                                   # если ещё не делали после обновления: доставит GigaAM, Silero, num2words
.venv-tts/bin/python talk_server.py          # LM Studio запущен; роль начальника отдела: --persona staff
```

Откройте http://localhost:8765 в Chrome, Arc или Safari, нажмите «Начать», разрешите микрофон. Если запрос
не появился, страница напишет причину; обычно это запрет в macOS (Системные настройки → Конфиденциальность и
безопасность → Микрофон → включить браузер и перезапустить его) или в настройках сайта (в Arc — ⌘⇧C). Подавление эха —
браузерное. Над разговором — регуляторы, они действуют сразу и запоминаются в браузере:

- **чувствительность в тишине** — пока модель молчит: правее — ловит тише, но чаще срабатывает на шум;
- **чувствительность перебивания** — пока модель говорит; микрофон слышит и её голос, поэтому порог строже;
  перебивает сама себя из динамиков — сдвиньте левее (или наденьте наушники);
- **перебить, если говорю дольше** — сколько нужно говорить, чтобы модель замолчала;
- **пауза до ответа** — сколько молчать до проверки конца реплики (обрывает на полуслове — увеличьте).

**Калибровка** (кнопка в шапке) выставляет регуляторы сама — под ваш микрофон, голос, комнату и громкость
динамиков; проходить один раз на новом месте или с новым микрофоном. Четыре шага по ~5 с: помолчать (фон),
прочитать фразу (ваш голос), помолчать, пока модель говорит тестовую фразу (сколько её слышит микрофон), и
перебить её. Порог в тишине ставится посередине между фоном и тихой частью вашей речи; порог перебивания —
выше эха модели и ниже вашей речи поверх неё; длительность перебивания — длиннее самого долгого срабатывания
на эхо. Итог применяется сразу и запоминается в браузере; если эхо почти так же громко, как ваш голос, стенд
посоветует наушники. Паузу до ответа калибровка не трогает — это дело привычки, а не акустики.

Индикатор слева — уверенность, что звучит речь, с отметками обоих порогов: зелёная — в тишине, красная —
перебивание. Значения при запуске сервера: `--vad`, `--barge-vad`, `--barge-ms`, `--end-ms`; ещё
`--max-silence-ms` (пауза, после которой реплика кончилась в любом случае, 1500 мс) и `--turn` (порог Smart Turn).
Под каждым ответом — задержка от конца вашей реплики до первого слова, первой фразы и первого звука.
